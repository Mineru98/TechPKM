Kotlin/Wasm 사용 방법을 다양한 예제를 통해 보여주는 프로젝트입니다. Compose Multiplatform으로 구축된 웹 애플리케이션, 브라우저 DOM API, Node.js 환경, 그리고 WASI 및 C interop 활용 방법을 포함하고 있습니다. 각 예제는 소스 코드와 실행을 위한 README를 제공하며, Kotlin의 WebAssembly 생태계를 실습하고 피드백을 나누기 위한 용도로 활용됩니다.
