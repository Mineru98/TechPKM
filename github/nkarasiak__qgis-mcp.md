QGIS MCP는 QGIS 데스크톱 GIS 소프트웨어를 Model Context Protocol(MCP)을 지원하는 AI 에이전트와 연결하는 프로젝트입니다. QGIS 플러그인과 FastMCP 기반 서버가 TCP 소켓으로 통신하여, AI 에이전트가 레이어 관리, 피처 편집, 처리 알고리즘 실행, 지도 렌더링 등 125개의 MCP 도구를 통해 QGIS를 직접 제어할 수 있습니다. Claude Code, Cursor, VS Code 등 다양한 MCP 클라이언트를 지원하며, QGIS 3.28~4.x와 호환됩니다.
