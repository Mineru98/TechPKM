Godogen은 사용자가 원하는 게임을 설명하면 AI가 아키텍처 설계부터 에셋 생성, 코드 작성, 테스트까지 자동으로 수행하여 완성된 Godot 4 프로젝트를 생성하는 도구입니다. Gemini와 Tripo3D를 활용해 2D/3D 아트를 제작하고, 실행 중인 게임의 스크린샷을 캡처하여 시각적 오류를 수정하는 피드백 루프를 갖추고 있으며, 일반 PC 하드웨어에서도 작동하는 것이 특징입니다.
