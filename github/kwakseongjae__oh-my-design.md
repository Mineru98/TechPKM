oh-my-design는 Toss, Stripe, LINE 등 500개 이상의 실제 제품에 대한 DESIGN.md 아카이브와, 한국어·일본어·중국어 등 CJK 화면에 최적화된 프론트엔드 스킬을 제공하는 프로젝트입니다. 코딩 에이전트(Claude Code, Codex, Cursor 등)가 CJK 텍스트 줄바꿈이나 디자인 스타일을 해치지 않고 자연스러운 UI를 만들도록 돕습니다. `npx oh-my-design-cli`로 설치하며 별도의 API 키나 MCP 서버 없이 사용할 수 있습니다.
