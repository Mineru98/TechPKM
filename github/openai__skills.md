이 프로젝트는 AI 에이전트가 발견하고 사용하여 특정 작업을 수행할 수 있는 지침, 스크립트 및 리소스의 모음인 '에이전트 스킬(Agent Skills)'을 위한 저장소입니다. OpenAI Codex와 통합되어 팀과 개인이 반복 가능한 방식으로 작업을 완료하는 데 필요한 기능을 패키징하고 배포하는 표준을 제공합니다. 사용자는 `.curated` 또는 `.experimental` 폴더의 스킬을 설치하여 자신의 에이전트 환경을 확장할 수 있습니다.
