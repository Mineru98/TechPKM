이 프로젝트는 Apple Intelligence의 핵심인 온디바이스 파운데이션 모델을 macOS 환경의 Python에서 사용할 수 있게 해주는 SDK입니다. Swift 앱 기능의 평가를 위한 배치 추론, 구조화된 출력을 위한 가이드 생성, 실시간 텍스트 생성 스트리밍 등의 기능을 제공합니다. Python 데코레이터를 활용한 타입 안전 응답 처리와 사용자 정의 모델 설정을 지원하여 macOS와 Python 간의 AI 연동을 강화합니다.
