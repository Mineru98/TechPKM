GeoPandas는 pandas 객체에 지리 공간 데이터 처리 기능을 추가하여 제공하는 파이썬 라이브러리입니다. shapely 기반의 기하학적 연산과 좌표 변환을 지원하며, 기존 pandas의 강력한 데이터 조작 기능을 공간 데이터 분석에 그대로 적용할 수 있습니다. 또한 matplotlib을 활용한 간편한 시각화와 다양한 공간 데이터 파일 포맷 읽기를 지원합니다.
