CLI 환경에서 Photoshop(PSD) 파일을 PNG로 변환하고 내부 텍스트를 추출할 수 있는 도구입니다. 별도의 네이티브 의존성 없이 Node.js와 PSD.js를 기반으로 동작하며, 단일 및 다중 파일 처리와 변환 후 미리보기 기능을 지원합니다.
