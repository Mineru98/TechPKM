SQLFluff는 다양한 SQL 방언을 지원하는 유연하고 설정 가능한 SQL 린터입니다. ELT 애플리케이션을 염두에 두고 설계되어 Jinja 템플릿과 dbt를 지원하며, 대부분의 린팅 오류를 자동으로 수정해 줍니다. PostgreSQL, Snowflake, BigQuery 등 30여 개 SQL 방언을 지원하고, `sqlfluff lint` 및 `sqlfluff fix` CLI 명령과 VS Code 확장, Docker 이미지로도 활용할 수 있습니다.
