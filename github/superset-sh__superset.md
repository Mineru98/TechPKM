Superset는 다중 CLI 코딩 에이전트를 동시에 실행하고 효율적으로 관리할 수 있도록 설계된 고성능 터미널 애플리케이션입니다. 각 작업을 별도의 Git worktree로 격리하여 에이전트 간의 간섭을 방지하고, 통합 모니터링 및 내장된 Diff 뷰어를 통해 변경 사항을 신속하게 검토할 수 있는 환경을 제공합니다. 터미널에서 실행 가능한 모든 CLI 기반 에이전트와 호환되며, 개발 워크플로우의 생산성을 크게 향상시키는 것을 목표로 합니다.
