Notion 플랫폼과의 연동 및 작업을 돕는 에이전트용 도구 모음 프로젝트입니다. Skills CLI를 사용하여 전체 도구를 일괄 설치하거나 특정 기능만 선택적으로 설치할 수 있습니다. 현재 Notion CLI(`ntn`)를 설치하고 워커 생성, 공개 API 요청, 파일 업로드 등을 수행할 수 있는 notion-cli 스킬이 제공됩니다.
