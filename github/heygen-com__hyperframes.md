AI 에이전트의 사용을 최우선으로 고려하여 설계된 오픈소스 HTML 기반 비디오 렌더링 프레임워크입니다. 별도의 빌드 단계나 React 없이 HTML과 CSS, GSAP만으로 비디오 컴포지션을 작성하고 결정론적으로 MP4로 렌더링할 수 있으며, AI 코딩 에이전트와의 원활한 연동을 위한 전용 스킬을 제공합니다.
