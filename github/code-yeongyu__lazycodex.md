LazyCodex는 복잡한 코드베이스를 위해 설계된 OpenAI Codex 전용 AI 에이전트 하니스입니다. 프로젝트 메모리 생성, 전략적 계획, 검증된 실행 완료 등의 기능을 제공하며, 작업별로 최적의 GPT 모델을 자동으로 라우팅하여 효율적인 에이전트 오케스트레이션을 달성합니다. 핵심 엔진인 oh-my-openagent(OmO)를 Codex 환경에 쉽게 설치하고 사용할 수 있도록 패키징한 배포 레이어 역할을 수행합니다.
