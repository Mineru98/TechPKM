AI 에이전트를 위해 설계된 고성능 헤드리스 브라우저 자동화 CLI 도구입니다. 빠른 Rust 네이티브 바이너리와 Node.js 폴백(Fallback)을 지원하며, `snapshot`과 `ref`를 활용한 LLM 친화적인 웹 상호작용 워크플로우를 제공합니다. 다양한 플랫폼(Chromium, iOS Simulator 등)과 통합이 가능하며, 세션 관리, 보안 옵션, 클라우드 브라우저 연결 등 풍부한 기능을 포함하고 있습니다.
