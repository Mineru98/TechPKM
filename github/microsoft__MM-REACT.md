MM-REACT는 ChatGPT와 전문 비전 전문가 풀을 통합하여 멀티모달 추론 및 행동을 수행하는 시스템 패러다임입니다. 이미지 파일 경로를 플레이스홀더로 활용해 ChatGPT가 필요한 시점에 객체 인식, 얼굴 분석, OCR 등의 외부 전문가 모델을 호출하도록 설계되었습니다. LangChain 기반으로 구축되었으며, Azure의 다양한 인지 서비스를 결합하여 복잡한 시각적 이해 작업을 해결합니다.
