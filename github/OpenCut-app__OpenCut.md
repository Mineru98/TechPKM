OpenCut은 웹, 데스크톱, 모바일 환경을 모두 지원하는 무료 오픈소스 영상 편집기입니다. 사용자의 동영상을 기기에만 저장하여 프라이버시를 보호하며, 캡컷(CapCut)처럼 간결하고 직관적인 인터페이스를 목표로 개발되고 있습니다. Next.js 기반의 웹 애플리케이션과 Rust 기반의 고성능 코어 모듈(GPU 컴포지터, WASM 바인딩 등)을 결합하여 크로스 플랫폼 환경에서 유연하게 동작하도록 설계되었습니다.
