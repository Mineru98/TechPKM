참조 이미지를 분석하여 프로그래밍 방식의 Three.js 3D 모델 코드로 재구성해 주는 AI 에이전트 스킬입니다. 사진 측량이나 메시 추출 대신 기본 도형, 셰이더, 생성 기하학을 활용해 애니메이션에 바로 사용할 수 있는 계층 구조를 포함한 모델을 생성합니다. 파이썬 스크립트가 검증과 게이팅을 담당하고 AI 모델은 시각적 판단과 코드 생성에만 토큰을 소비하도록 설계되어 효율적입니다.
