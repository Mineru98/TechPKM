PyTorch를 기반으로 YOLOv3를 최소한으로 구현한 프로젝트로, 모델 학습, 추론 및 평가 기능을 지원합니다. YOLOv4 및 YOLOv7 가중치와도 호환되며, Python API나 CLI를 통해 사용자 정의 데이터셋 학습이 가능합니다. 특히 가볍고 모듈화된 구조로 제공되어 실시간 객체 탐지 연구 및 프로젝트에 활용하기 적합합니다.
