코딩 에이전트에게 시각적 식별 체계를 전달하기 위한 DESIGN.md 포맷 명세 및 CLI 도구입니다. YAML 프론트매터로 기계가 읽을 수 있는 디자인 토큰을 정의하고, 마크다운 본문으로 디자인 의도와 적용 방법을 설명하여 에이전트가 일관된 UI를 구현하도록 돕습니다. 린트, 비교, 내보내기 등의 기능을 제공하며 W3C 디자인 토큰 표준과의 상호 운용성을 지원합니다.
