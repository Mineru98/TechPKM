p5.js와 p5.brush를 사용해 Claude AI로 캐릭터 애니메이션을 제작할 수 있는 스타터 키트입니다. 코드, 가이드, 에셋이 포함되어 있어 Claude Code 같은 코딩 에이전트에 프롬프트만으로 스토리보드 작성부터 샷 단위 렌더링, MP4 비디오 출력까지 수행시킬 수 있습니다. "I'm Upping My P(doom)" 뮤직비디오 제작 경험을 바탕으로 만들어졌으며, 수채화 스타일의 붓질과 2D 애니메이션 규칙을 담은 ANIMATION_GUIDE.md가 핵심 문서입니다.
