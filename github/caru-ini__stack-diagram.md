stack-diagram은 기술 스택을 한 문장으로 설명하면 공식 로고가 포함된 아키텍처 다이어그램을 자동으로 생성해주는 AI 에이전트 스킬이다. Claude Code, Codex, Cursor 등 skills을 지원하는 에이전트에서 동작하며, 라이트/다크 테마 다이어그램, 자체 포함 HTML 파일, PNG, React 컴포넌트 등 다양한 형태의 결과물을 제공한다. 로고는 svgl, devicon, AWS 공식 아이콘 등에서 빌드 시점에 가져오며, 생성된 다이어그램은 아티팩트로 공유하거나 공개 갤러리에 게시할 수 있다.
