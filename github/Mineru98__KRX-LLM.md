KRX-LLM은 금융 도메인에 특화된 LLM 파인튜닝 프로젝트로, LoRA와 UnSloth를 활용해 gemma-2 계열 모델(예: gemma-2-2b-finance)을 학습할 수 있다. 학습 스크립트와 Streamlit 기반 데모(web-pandas-ai)를 제공하여 모델 학습 및 체험 환경을 지원한다.
