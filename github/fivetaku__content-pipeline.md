주제를 입력하면 리서치, 카드뉴스 기획, AI 이미지 생성, HTML 카드뉴스 제작, TTS 나레이션, Remotion 기반 영상 렌더링까지 6단계 파이프라인을 자동으로 실행하는 Claude Code 스킬입니다. 각 단계별로 체크포인트를 제공하여 결과를 확인하고 수정하거나 건너뛸 수 있어 유연하게 콘텐츠를 제작할 수 있습니다. API 키 설정에 따라 리서치부터 영상 제작까지 전체 과정을 활용하거나 텍스트 기반 카드뉴스까지만 제한적으로 사용할 수도 있습니다.
