Andrej Karpathy가 지적한 LLM 코딩의 일반적인 문제점(잘못된 가정, 과도한 복잡성, 불필요한 코드 수정 등)을 해결하기 위해 작성된 단일 `CLAUDE.md` 가이드라인 프로젝트입니다. 코드 작성 전 명확한 사고, 단순성 우선, 정밀한 변경, 목표 주도 실행의 네 가지 핵심 원칙을 제시하여 AI 어시스턴트의 코딩 행동을 개선하는 데 목적이 있습니다. Claude Code 플러그인이나 Cursor 프로젝트 규칙으로 적용할 수 있어 다양한 개발 환경에서 손쉽게 활용할 수 있습니다.
