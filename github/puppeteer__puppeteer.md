Puppeteer는 DevTools Protocol이나 WebDriver BiDi를 통해 Chrome 및 Firefox 브라우저를 제어할 수 있는 고수준 API를 제공하는 JavaScript 라이브러리입니다. 기본적으로 UI 없이 동작하는 헤드리스 모드로 실행되며, 웹 페이지 내비게이션, 키보드 입력, 요소 클릭 등의 브라우저 자동화 작업을 손쉽게 구현할 수 있습니다. 웹 스크래핑, 테스트 자동화, 크롬 확장 프로그램 개발 등 다양한 웹 자동화 시나리오에 활용하기 적합합니다.
