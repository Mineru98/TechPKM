HEIC/HEIF 이미지를 JPEG 또는 PNG 형식으로 변환해 주는 JavaScript 라이브러리입니다. Node.js 환경뿐만 아니라 브라우저 환경에서도 사용할 수 있으며, 단일 이미지 및 파일 내 모든 이미지 변환을 지원합니다. 동기식 작업이 수반되므로 동시성이 높은 환경에서는 워커 스레드 사용을 권장합니다.
