Magnitude는 Vision AI를 활용해 자연어로 브라우저를 제어할 수 있는 오픈소스 프로젝트입니다. 웹 인터페이스의 시각적 이해와 정확한 액션을 결합하여 작업 자동화, 데이터 추출, 웹 테스트 등 다양한 용도로 활용됩니다. DOM 구조에 의존하지 않는 시각적 기반 아키텍처로 현대 웹 환경과 데스크톱 애플리케이션에도 확장 가능한 솔루션을 제공합니다. 고수준 작업부터 저수준 액션까지 유연하게 제어할 수 있으며, 캐시 시스템을 통해 재현 가능한 자동화를 지향합니다. 주요 기술 스택은 TypeScript 기반으로 구축되었습니다.
