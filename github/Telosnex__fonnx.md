FONNX는 모바일, 웹, 데스크톱을 아우르는 Flutter 환경에서 ONNX 모델을 네이티브로 실행할 수 있게 하는 라이브러리입니다. iOS, Android, Web 등 각 플랫폼의 하드웨어 가속 기술을 활용하여 Whisper, Silero VAD, 텍스트 임베딩 모델 등을 효율적으로 구동합니다. 이 프로젝트는 기기 내에서 직접 머신러닝 추론을 수행하여 지연 시간을 단축하고 개인정보 보호를 강화하는 것을 목표로 합니다.
