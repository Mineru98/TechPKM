웹 브라우저 환경에서 완전 기능의 터미널을 제공하는 프론트엔드 컴포넌트입니다. VS Code, Hyper 등 유명 프로젝트에 탑재되어 있으며, Vim이나 Tmux 같은 Curses 기반 애플리케이션 지원, 옵셔널 GPU 가속 렌더링, 풍부한 유니코드 및 IME 지원이 가능합니다. 핵심 라이브러리는 외부 의존성이 전혀 없이 독립적으로 동작하며, 다양한 애드온을 통해 웹 링크 감지, 이미지 렌더링, 검색 등의 기능을 확장할 수 있습니다.
