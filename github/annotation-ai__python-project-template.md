Annotation-AI 내부 사용을 위해 제작된 파이썬 프로젝트 템플릿입니다. 코드 포맷팅, 린팅, 단위 테스트 설정이 포함되어 있으며, Makefile 명령어를 통해 쉽게 환경 구성과 검증을 수행할 수 있습니다. 또한 pre-commit 훅과 GitHub Actions를 활용하여 커밋 및 PR 단계에서 코드 품질을 자동으로 검증하도록 구성되어 있습니다.
