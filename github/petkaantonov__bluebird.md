Bluebird는 혁신적인 기능과 성능에 초점을 맞춘 완전한 기능을 갖춘 JavaScript Promise 라이브러리입니다. Promises/A+ 1.1 규격을 준수하며, 높은 테스트 커버리지(98%)를 자랑합니다. 다만 README에서는 네이티브 Promise가 안정화된 현재, 매우 오래된 브라우저나 EoL Node.js 지원 등 특수한 경우에만 사용할 것을 권장하고 있습니다.
