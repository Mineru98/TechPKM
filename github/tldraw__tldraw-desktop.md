tldraw와 Electron을 기반으로构建된 `.tldr` 파일 전용 데스크톱 에디터입니다. macOS, Windows, Linux 등 다양한 플랫폼을 지원하며, 자동 업데이트 기능을 내장하고 있습니다. 또한 앱 실행 시 로컬 HTTP 서버를 통해 문서의 캔버스를 프로그래밍 방식으로 제어하거나 AI 코딩 보조 도구와 연동할 수 있는 로컬 Canvas API를 제공합니다.
