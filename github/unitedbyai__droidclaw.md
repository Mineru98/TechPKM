안드로이드 기기의 접근성 트리와 ADB를 활용하여, 화면을 인지하고 추론한 후 행동하는 자율적인 AI 에이전트입니다. 사용자가 자연어로 목표를 입력하면 별도의 API 통합 없이 설치된 앱을 통해 업무를 자동으로 수행하며, Python 스크립트 방식이 아닌 TypeScript로 작성된 커널을 사용합니다.
