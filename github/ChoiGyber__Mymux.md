Tauri 2와 Rust로 제작된 Windows 데스크톱 터미널 멀티플렉서입니다. 하나의 창에서 여러 셸을 분할 패인으로 관리하고, SSH/SFTP 접속, 파일 탐색기, 파일 뷰어, AI 제어가 가능한 내장 브라우저를 통합하여 제공합니다. 별도의 프론트엔드 빌더 없이 정적 웹 자원을 바이너리에 임베드하여 가볍고 효율적인 개발 환경 구축을 지원합니다.
