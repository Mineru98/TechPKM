Hammerspoon은 macOS 환경에서 강력한 자동화를 구현할 수 있도록 운영체제와 Lua 스크립팅 엔진을 연결해 주는 도구입니다. 다양한 시스템 기능을 노출하는 확장 기능 세트를 제공하며, 사용자는 Lua 스크립트를 작성하여 macOS 환경의 여러 측면을 세밀하게 제어할 수 있습니다. 기본적으로는 아무 동작도 수행하지 않으므로, 사용자가 직접 설정 파일을 작성하여 필요한 자동화 로직을 구성해야 합니다.
