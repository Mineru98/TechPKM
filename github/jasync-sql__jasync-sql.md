Netty 기반으로 구축된 Kotlin 언어의 비동기 데이터베이스 드라이버로, MySQL과 PostgreSQL을 지원합니다. 기존 Scala 기반 라이브러리를 Kotlin으로 포팅하여 높은 성능과 신뢰성을 제공하며, R2DBC 및 Spring WebFlux 등 주요 리액티브 프레임워크와 연동하여 대규모 트래픽 환경에서 효과적으로 사용할 수 있습니다.
