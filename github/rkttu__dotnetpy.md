DotNetPy는 현대 .NET 애플리케이션에서 Python 코드를 원활하게 실행할 수 있게 하는 라이브러리입니다. C# 코드 내에서 문자열로 Python 로직을 정의하고 실행할 수 있으며, 데이터 흐름을 완벽하게 제어할 수 있습니다. 파일 기반 앱(.NET 10+) 및 Native AOT를 지원하며, uv를 통한 선언적 Python 환경 관리 기능을 제공합니다. Apache 2.0 라이선스로 배포되며, 통계 계산, AI/데이터 과학 워크플로우 등 다양한 시나리오에 최적화되어 있습니다.
