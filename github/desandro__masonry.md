벽돌을 쌓는 것처럼 요소를 수직 공간에 최적화하여 배치하는 **계단식 그리드 레이아웃(Cascading grid layout) 라이브러리**입니다. jQuery, 바닐라 자바스크립트, HTML 속성을 통한 다양한 초기화 방식을 지원하며, npm이나 Bower 등의 패키지 매니저를 통해 설치할 수 있습니다. 8년 이상 유지보수된 검증된 라이브러리로, MIT 라이선스 하에 사용할 수 있습니다.
