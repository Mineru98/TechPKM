arq는 Python의 asyncio와 Redis를 기반으로 구축된 경량 작업 큐(Job Queue) 라이브러리입니다. 비동기 처리 환경에서 백그라운드 작업을 관리하고 실행할 수 있도록 설계되었습니다. 다만, 현재 이 프로젝트는 유지보수 모드로 전환된 상태입니다.
