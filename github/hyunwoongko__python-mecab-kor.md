기존 python-mecab-ko 패키지의 유지 보수 중단 문제를 해결하기 위해, 설치 이슈를 개선하여 직접 관리하는 한국어 형태소 분석기 패키지입니다. 형태소 추출, 명사 추출, 품사 태깅 및 상세 분석 기능을 제공하며, 공백 유지 옵션 등 세부적인 처리가 가능합니다. 리눅스 및 macOS 환경에서 정상적으로 동작하는 것을 지원합니다.
