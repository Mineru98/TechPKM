OpenAI의 Codex 에이전트와 직접 통신하여 코드베이스를 자동으로 정리하고 개선하는 CLI 도구입니다. 리팩토링 후보 탐색, 계획 수립 및 개선, 구현, 리뷰로 이어지는 일련의 에이전트 실행 계획 루프를 자동화하여 수동 프롬프트 체인을 대체합니다. 대규모 기능 개발을 위한 빌더 모드와 목표 기반 실행 모드를 제공하며, 철저한 상태 검증과 상세한 실행 로그를 통해 장기 자율 실행의 신뢰성을 보장합니다.
