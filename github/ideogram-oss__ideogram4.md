Ideogram 4는 디자인 영역에서 최고 수준의 성능을 자랑하는 Ideogram의 첫 오픈 가중치 텍스트-이미지 생성 기반 모델입니다. 기존 모델의 미세조정이 아닌 완전히 처음부터 학습된 단일 스트림 디퓨전 트랜스포머(DiT) 아키텍처를 기반으로 하며, 구조화된 JSON 프롬프트를 통해 레이아웃, 색상 팔레트, 텍스트 렌더링 등을 세밀하게 제어할 수 있는 것이 특징입니다. 최대 2K 해상도를 기본 지원하며, 오픈 가중치 모델 중 최고 수준의 텍스트 렌더링 및 다국어 처리 능력을 제공합니다.
