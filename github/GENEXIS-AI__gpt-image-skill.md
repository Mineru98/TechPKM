Codex나 Claude Code 같은 로컬 코딩 에이전트에서 사용자의 ChatGPT 구독을 기반으로 GPT 이미지를 생성하고 편집할 수 있게 해주는 스킬입니다. 별도의 OpenAI Images API나 API 키 없이 내장된 `$imagegen` 기능을 활용하며, 직접적인 프롬프트는 그대로 전달하고 에이전트에 위임된 다중 디자인 개념은 각각에 맞는 독립적인 프롬프트로 개발하여 처리합니다. 참조 파일 기반 편집, 이어서 수정하기, 제한된 병렬 배치 생성 등을 지원하여 프로젝트 워크스페이스 내에서 안전하고 효율적으로 이미지 작업을 수행할 수 있습니다.
