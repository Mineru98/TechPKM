Terminus-KIRA는 Terminal-Bench 환경에서 최신 언어 모델의 성능을 극대화하기 위해 Terminus 2를 기반으로 구축된 에이전트 하네스입니다. ICL 방식의 JSON 파싱 대신 네이티브 툴 호출을 도입하고, 멀티모달 이미지 분석 및 마커 기반 실행 최적화 등 최소한의 변경만으로도 모델의 성능을 크게 향상시키는 것이 핵심 특징입니다.
