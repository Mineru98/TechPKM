oh-my-hermes(OMH)는 Hermes Agent 위에 구축된 운영 레이어로, 기존 Hermes 환경을 대체하지 않고 워크플로우 관리, 증거 기반 검증, 혼합 모델 라우팅 등의 강력한 제어 기능을 추가합니다. 계획 수립, 연구, 코딩, QA, 성능 측정 등의 작업을 구조화된 단계와 병렬 실행으로 처리하며, 준비 상태와 실제 실행 완료 상태를 명확히 구분하여 신뢰할 수 있는 결과를 보장합니다.
