파워 유저를 위해 Claude Code의 기본 기능을 확장하는 플러그인 모음집입니다. 다중 AI 모델 의견 종합, 요구사항 정제, 개발 커뮤니티 탐색, 웹 UI 기반 리뷰, 이메일 및 캘린더 연동, 카카오톡 메시지 발송, 한국어 팟캐스트 자동 생성 및 유튜브 업로드 등 다양한 실무 자동화 기능을 제공합니다. 복잡한 작업을 동적 에이전트 팀 구성으로 해결하고, 세션 분석 및 기술 의사결정을 지원하여 개발 워크플로우의 생산성을 크게 향상시킵니다.
