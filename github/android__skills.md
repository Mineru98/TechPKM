Android skills는 developer.android.com의 모범 사례에 따라 Android 개발을 이해하고 실행할 수 있도록 AI 에이전트에 최적화된 모듈형 지침(SKILL.md)을 제공하는 저장소입니다. 평가에서 LLM이 부족한 사용 사례와 워크플로우에 집중하며, Android CLI 또는 Claude Code, Codex 등의 에이전트 플러그인으로 설치할 수 있습니다.
