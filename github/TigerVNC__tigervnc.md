TigerVNC는 RealVNC 4와 X.org 코드 기반으로 개발된 고속 VNC 원격 데스크톱 소프트웨어로, 네트워크 상의 다른 컴퓨터에서 실행 중인 가상 데스크톱 환경을 원격으로 조회하고 조작할 수 있게 해줍니다. TightVNC의 차세대 개발 노력에서 출발하여 2009년에 독립 프로젝트로 분리되었으며, libjpeg-turbo JPEG 코덱을 활용해 크게 가속화된 Tight 인코딩을 지원합니다. 크로스플랫폼 뷰어(vncviewer)와 Windows(winvnc), Unix/Linux(Xvnc, x0vncserver, w0vncserver 등)용 서버 프로그램들을 제공합니다.
