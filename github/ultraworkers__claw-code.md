Claw Code는 Anthropic API 등을 활용하여 동작하는 CLI 기반 AI 에이전트 하네스의 공개 Rust 구현체입니다. 소스 코드를 직접 빌드하여 사용해야 하며, 프롬프트 실행 및 세션 관리 등 코딩 워크플로우 지원을 핵심 목표로 합니다. 이 프로젝트는 Anthropic과는 무관한 독립적인 커뮤니티 구현체입니다.
