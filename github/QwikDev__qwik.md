초기 자바스크립트 번들 크기를 최소화하여 즉각적인 페이지 로딩을 제공하는 웹 프레임워크입니다. 서버에서 중단된 시점부터 애플리케이션을 이어서 실행하는 'Resumable' 방식과, 사용자 상호작용 시에만 필요한 코드를 정밀하게 로드하는 'Precision Lazy-loading'을 통해 복잡한 웹사이트에서도 최고의 성능을 보장합니다.
