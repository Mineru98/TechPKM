DOM 리플로우를 유발하지 않고 멀티라인 텍스트의 높이를 측정하고 수동으로 레이아웃할 수 있는 JavaScript/TypeScript 라이브러리입니다. 브라우저의 캔버스 엔진을 기반으로 한 고유한 텍스트 측정 로직을 제공하여, 가상화 및 메이슨리 등 복잡한 웹 UI 구현 시 정확한 텍스트 크기 계산을 가능하게 합니다. DOM, Canvas, SVG 등 다양한 타겟에 대한 수동 렌더링과 리치 텍스트 인라인 흐름 처리를 지원합니다.
