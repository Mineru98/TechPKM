Agent Skills는 시니어 엔지니어의 워크플로우, 품질 게이트, 베스트 프랙티스를 AI 코딩 에이전트가 일관되게 따르도록 패키징한 프로덕션급 엔지니어링 스킬 모음집이다. 정의·계획·빌드·검증·리뷰·배포 전 개발 수명주기를 아우르는 25개의 스킬과 9개의 슬래시 명령(`/spec`, `/plan`, `/build`, `/test`, `/review`, `/ship` 등)을 제공하며, Google의 엔지니어링 문화에서 온 원칙들을 단계별 워크플로우에 내장하고 있다. Claude Code, Cursor, Codex, Copilot, Gemini CLI 등 70개 이상의 에이전트에 설치해 사용할 수 있다.
