React 애플리케이션에서 A/B 테스트를 쉽게 구현할 수 있도록 돕는 컴포넌트 라이브러리입니다. `<Experiment>`와 `<Variant>` 컴포넌트를 통해 사용자에게 무작위로 변형을 제공하고, 로컬 스토리지에 결과를 저장하며 Mixpanel이나 Segment 같은 분석 도구와의 연동을 지원합니다. 서버 사이드 렌더링과 다중 컴포넌트 간의 실험 조율도 가능하여 실무 환경의 테스트 요구를 충족합니다.
