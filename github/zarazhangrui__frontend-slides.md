Claude Code를 위한 스킬로, 디자인 지식 없이도 애니메이션이 풍부한 HTML 프레젠테이션을 처음부터 생성하거나 기존 PowerPoint 파일을 웹 슬라이드로 변환할 수 있게 해줍니다. 외부 의존성 없이 단일 HTML 파일로 출력되며, 시각적 미리보기를 통해 원하는 스타일을 직관적으로 선택하는 '보여주기' 방식을 채택했습니다. 생성된 결과물은 Vercel 배포나 PDF 내보내기를 통해 손쉽게 공유할 수 있습니다.
