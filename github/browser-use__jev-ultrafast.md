Jev Ultrafast는 동적으로 인덱싱된 액션 공간을 사용하는 초고속 브라우저 에이전트입니다. TypeSafe의 Jev가 하나의 목표만 주어지면 연산(CLICK, TYPE_TEXT 등)과 대상 요소를 단 한 번의 네트워크 요청으로 결정하고, 텍스트 입력 시에만 소형 LLM이 텍스트를 생성합니다. 스크린샷 없이 구조화된 DOM 상태를 활용해 Google Flights 검색을 약 7초 만에 수행하며, 라이브러리로도 재사용할 수 있습니다.
