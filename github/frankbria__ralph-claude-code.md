Claude Code를 활용해 프로젝트를 자율적으로 개발하는 루프를 구현한 Bash 기반 도구입니다. 무한 루프 방지를 위한 이중 조건 종료 감지, API 호출 속도 제한, 서킷 브레이커 등의 안전장치를 내장하고 있으며, 세션 연속성 및 만료 관리 기능을 제공합니다. 기존 프로젝트에 쉽게 적용할 수 있는 설정 마법사와 PRD 문서 자동 임포트 기능을 지원합니다.
