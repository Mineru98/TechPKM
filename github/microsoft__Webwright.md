Webwright는 코딩 모델을 최고 수준의 브라우저 에이전트로 변환하는 경량화된 프레임워크입니다. 기존의 상태 유지 방식 브라우저 상호작용 대신, 에이전트가 터미널에서 Playwright 기반의 파이썬 스크립트를 작성하고 실행하여 웹 작업을 수행하는 '코드-액션(Code-as-Action)' 방식을 채택했습니다. 복잡한 다중 에이전트 시스템이나 오케스트레이션 계층 없이 터미널, 브라우저, 모델만으로 구성되어 있으며, Claude Code나 Codex 등 기존 코딩 에이전트의 플러그인으로도 손쉽게 통합할 수 있습니다.
