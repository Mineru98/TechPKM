Stanford Alpaca 모델의 학습 방식을 기반으로 한국어 지시사항을 수행하도록 파인튜닝된 한국어 언어 모델 프로젝트입니다. Polyglot-ko와 LLAMA를 백본으로 사용하여 다양한 크기의 모델을 제공하며, QLoRA 및 Full Finetune 등 실제 학습과 추론을 위한 코드와 데이터셋 제작 과정을 함께 제공합니다. 대화 맥락을 이해하는 채팅형 모델까지 지원하여 한국어 특화 LLM 활용 사례를 보여줍니다.
