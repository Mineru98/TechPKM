React 환경에서 캔버스 기반 드로잉을 쉽게 구현할 수 있도록 도와주는 강력한 컴포넌트입니다. 브러시 크기 및 색상 조절, 이미지 불러오기, 그림 데이터 저장 및 복원, 되돌리기 기능 등을 기본적으로 제공하며, 패닝과 줌 기능도 지원합니다. lazy-brush의 영향을 받아 자연스러운 선 그리기 경험을 제공하는 것이 특징입니다.
