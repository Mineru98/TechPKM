Node.js 환경에서 웹 브라우저의 동작을 에뮬레이트하기 위해 WHATWG DOM 및 HTML 표준을 순수 JavaScript로 구현한 라이브러리입니다. 주로 실제 웹 애플리케이션를 대상으로 하는 테스트 및 웹 스크래핑에 유용하게 사용되며, HTML 파싱, 스크립트 실행, 가상 콘솔, 쿠키 관리 등의 기능을 제공합니다. 단, 페이지 내비게이션이나 CSS 레이아웃 계산 등 일부 웹 플랫폼 기능은 지원 범위에 포함되지 않습니다.
