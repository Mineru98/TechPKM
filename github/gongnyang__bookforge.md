bookforge는 Claude Code와 OpenAI Codex에서 동작하는 에이전트 스킬로, 마크다운 원고를 표지·목차·장 도비라·판권면 등 실제 단행본의 구조를 갖춘 상업도서급 전자책 PDF로 조판합니다. 6종의 스타일 팩(실용서·리포트·학술·에세이·백서·매거진)과 17종의 기계 품질 게이트가 조판 품질을 강제하며, AntV·SVG 기반 도해 트랙과 뮤테이션 스위트로 게이트 감도까지 회귀 검증합니다.
