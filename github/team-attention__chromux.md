AI 에이전트가 사용자의 실제 크롬 환경에서 로그인 상태를 유지하고 봇 탐지를 피해 병렬로 웹 브라우징을 수행할 수 있도록 돕는 제로 의존성 탭 컨트롤러입니다. Playwright나 Puppeteer 없이 Node.js 내장 모듈만을 사용하여 CDP(Chrome DevTools Protocol)에 직접 연결하며, QA 및 일반 작업용 호환성 모드와 대규모 크롤링에 최적화된 모드를 제공합니다.
