Chat On Steroids(CoS)는 ChatGPT 대화를 Codex 스타일의 로컬 코딩 워크스페이스로 변환해주는 독립 오픈소스 데스크톱 애플리케이션이다. 파일 읽기/편집, 테스트 실행, 터미널 유지 등 로컬 도구를 MCP로 연결하고, 여러 워커에 작업을 분배하며 Goal/Loop, Compact & Resume 기능으로 긴 작업을 관리할 수 있다. ChatGPT 개발자 모드와 Chrome 확장을 통해 연동되며, OpenAI 이용약관 내 책임 있는 사용을 강조하고 MIT 라이선스로 배포된다.
