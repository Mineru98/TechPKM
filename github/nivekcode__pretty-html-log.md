HTML 문자열을 콘솔에 문법 강조 및 예쁘게 출력해 주는 도구입니다. JavaScript/TypeScript 코드 내 모듈로 임포트하거나 CLI 및 npm 스크립트를 통해 빌드 과정에서 사용할 수 있습니다. Dracula, Material, Vscode 등 세 가지 테마를 제공하며, highlight.js 핵심 알고리즘을 기반으로 HTML 하이라이팅에 맞게 최적화되었습니다.
