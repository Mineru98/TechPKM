Claude Code, Codex, OpenCode 등 다양한 코딩 에이전트의 작업 세션을 한눈에 관리하고 재사용할 수 있도록 설계된 터미널 기반 멀티플렉서입니다. 에이전트와의 대화 내용을 스킬셋처럼 보존하고 검색하며, 여러 프로젝트와 에이전트를 안전한 백그라운드에서 동시에 실행하고 전환할 수 있는 인터페이스를 제공합니다.
