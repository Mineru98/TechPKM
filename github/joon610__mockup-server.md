프론트엔드와 백엔드가 동시에 개발할 때 발생할 수 있는 API 연동 문제를 사전에 방지하기 위한 데스크톱 가짜 서버입니다. 디렉토리와 JSON 파일만으로 API 경로와 응답 데이터를 구성할 수 있으며, GET, POST, PUT, DELETE 등 CRUD 요청을 지원합니다. 전자(Electron) 기반 앱으로 제공되어 별도의 서버 구축 없이 GitHub를 통해 프론트엔드 및 백엔드 개발자 간에 API 명세를 쉽게 공유하고 관리할 수 있습니다.
