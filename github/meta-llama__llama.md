이 프로젝트는 Meta가 개발한 Llama 2 대형 언어 모델(7B~70B)의 추론을 위한 최소한의 예제 코드와 모델 가중치를 제공합니다. 사용자는 공식 웹사이트에서 라이선스를 승인받은 후 모델을 다운로드하여 로컬 환경에서 텍스트 완성 및 채팅 기능을 실행할 수 있습니다. 참고로, 이 저장소는 현재 라마 3.1 출시와 함께 기능 통합으로 인해 공식적으로 사용 중단(Deprecated)되었으며, 관련 기능은 새로운 통합 저장소로 이관되었습니다.
