부산 연합 IT 동아리 PROJECT의 홈페이지로, 기존 환경에서 NEXT.js로 이전을 진행 중인 프로젝트입니다. TypeScript와 Next.js를 기반으로 구축되었으며, 상태 관리를 위해 Redux와 Redux-Saga를 사용합니다. Storybook과 Jest를 활용하여 컴포넌트 개발 및 테스트 환경을 체계적으로 관리하고 있습니다.
