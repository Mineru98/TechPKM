Node.js 환경의 터미널(TTY)에서 사용할 수 있는 우아하고 인터랙티브한 로딩 스피너 라이브러리입니다. 다양한 스타일과 색상 옵션을 제공하며, Promise 기반 비동기 작업의 진행 상황을 시각적으로 표현하는 데 적합합니다. 자동으로 커서를 숨기거나 입력 처리를 관리하는 기능을 포함하여 CLI 애플리케이션의 사용자 경험을 개선하는 데 특화되어 있습니다.
