`kmsg`는 macOS 환경에서 카카오톡 메시지를 CLI로 읽고 보낼 수 있는 도구입니다. 단순한 수동 실행을 넘어 AI Agent나 MCP(Model Context Protocol)와 연동하여 자동화 파이프라인 구성을 지원합니다. Accessibility API를 활용하며, JSON 출력 및 디버깅 기능을 제공하여 유연한 스크립팅이 가능합니다.
