한글과컴퓨터의 HWP 문서 파일을 읽고 JSON, Markdown, HTML 등의 형식으로 변환해 주는 멀티 플랫폼 라이브러리입니다. Rust로 작성된 핵심 파싱 로직을 기반으로 Node.js, Web(WASM), React Native 환경에서 모두 사용할 수 있으며, CLI 도구를 통해 배치 처리 및 이미지 추출도 지원합니다.
