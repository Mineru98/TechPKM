GPT-2 토크나이저의 자바 구현체로, 텍스트를 토큰으로 인코딩하고 다시 텍스트로 디코딩하는 기능을 제공합니다. BPE(BPE) 알고리즘을 기반으로 동작하며, 리소스 디렉토리에 어휘 파일을 추가하여 간편하게 초기화 및 사용할 수 있습니다. Spring Boot 환경 등 자바 프로젝트에서 GPT-2 모델과 호환되는 텍스트 전처리가 필요할 때 유용합니다.
