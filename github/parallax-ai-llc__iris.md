Iris는 Parallax AI 워크플로우 제품의 오픈(fair-code) 코어로, 브라우저에서 노드 그래프 기반 AI 워크플로우를 만들고 자신의 API 키(BYOK)로 로컬에서 실행할 수 있는 자동화 도구입니다. `npx iris-flow`로 로컬 웹 앱을 실행하거나 Electron 데스크톱 앱으로 오프라인 실행, 배치 작업, 스케줄링을 지원합니다. 실행 엔진, 노드 카탈로그, 에디터는 공개되어 있으며, 호스트 포트 아키텍처를 통해 클라우드/로컬/데스크톱 환경에서 동일한 엔진을 재사용할 수 있습니다.
