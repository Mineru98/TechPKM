이 프로젝트는 Aseprite의 픽셀 아트 및 애니메이션 기능을 AI 어시스턴트에게 노출하는 MCP(Model Context Protocol) 서버입니다. Go로 작성되었으며, 자연어 명령을 통해 스프라이트 생성, 드로잉, 색상 관리, 디더링 등의 전문적인 작업을 자동화할 수 있습니다. Claude Desktop 등 MCP 클라이언트와 통합하여 작업 흐름을 효율화할 수 있습니다.
