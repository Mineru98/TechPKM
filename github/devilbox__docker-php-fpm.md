다양한 PHP 버전(5.2~8.2)과 플레이버(base, mods, prod, slim, work)를 제공하는 기능적인 PHP-FPM Docker 이미지 모음입니다. 호스트와 컨테이너 간의 볼륨 권한 동기화 문제를 해결하며, 개발에 필요한 다양한 CLI 도구와 PHP 확장 모듈을 기본적으로 지원합니다. 사용자가 직접 원하는 PHP 확장 모듈을 추가하여 커스텀 이미지를 손쉽게 빌드할 수도 있습니다.
