Ouroboros 핵심(Core) OS에서 제공하는 안정적인 기본 요소들을 조합하여 도메인별 워크플로우를 구성할 수 있도록 지원하는 사용자 수준(UserLevel) 플러그인 생태계입니다. 이 저장소는 로컬 환경에서 동작하는 플러그인 계약(Contract)의 최소 기능 제품(MVP)과 참조 플러그인 패키지들을 제공하여 전체 레지스트리나 마켓플레이스 구축 전에 계약 구조를 명확히 하는 것을 목적으로 합니다. GitHub PR 관리, OpenAI 및 Anthropic 스킬 통합, 자동화된 연구 및 디버깅과 같은 다양한 외부 에이전트 및 도구들을 안전한 권한 및 감사(Audit) 모델과 함께 체계적으로 흡수(Assimilation)하고 확장하는 데 중점을 둡니다.
