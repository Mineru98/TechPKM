OpenAI Codex CLI를 위한 멀티 에이전트 오케스트레이션 레이어로, 단일 세션 에이전트를 역할 기반의 협업 시스템으로 확장해 주는 도구입니다. 팀 오케스트레이션(tmux), 영구 상태 관리, MCP 서버 연동 등을 통해 대규모 작업을 구조화하고 자동화하며, `omx team`과 같은 명령어로 병렬 작업 흐름을 제어할 수 있습니다.
