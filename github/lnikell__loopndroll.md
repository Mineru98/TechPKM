OpenAI Codex가 작업이 완료되기 전에 중지되는 문제를 해결하기 위한 로컬 기반 자동화 도구입니다. Codex Hooks를 활용하여 무한 실행, 완료 검사(테스트/린트 등) 통과 시까지 반복, 사용자 응답 대기 등 다양한 모드를 지원합니다. Telegram이나 Slack을 연동하면 자리를 비운 상태에서도 진행 상황을 모니터링하고 작업을 리다이렉트할 수 있습니다.
