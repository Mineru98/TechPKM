ChatGPT To Codex는 macOS와 Windows에서 동작하는 로컬 MCP·Actions 런타임으로, ChatGPT가 사용자가 지정한 프로젝트 폴더 안에서 파일 읽기, 코드 검색, 패치 적용, 테스트 실행, E2E 스크린샷 캡처까지 수행할 수 있게 해줍니다. 소스 코드는 로컬에 유지되며, Owner Token 승인과 해시 기반 패치 등 안전장치를 통해 사용자가 편집 범위를 통제합니다. "ChatGPT가 생각하고, 내 컴퓨터가 실행하며, 사용자가 결과를 검토한다"는 모델로 실제 로컬 개발 워크플로를 자동화하는 것이 목적입니다.
