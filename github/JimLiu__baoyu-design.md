claude.ai/design의 디자인 엔진을 로컬 에이전트(Cursor, Claude Code 등)에서 실행할 수 있도록 패키징한 에이전트 스킬입니다. 별도의 웹사이트나 구독 없이 에디터 내에서 UI 목업, 인터랙티브 프로토타입, 와이어프레임, 프레젠테이션 등을 자체 포함된 HTML 파일로 생성할 수 있습니다. Figma 파일이나 기존 코드베이스를 디자인 소스로 가져오고, 생성된 결과물을 PPTX로 내보내는 등 실무적인 디자인 워크플로우를 로컬 환경에서 완전하게 지원합니다.
