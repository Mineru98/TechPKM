Claude Code를 위한 스킬 세트로, React Native 및 Expo 모바일 앱을 EAS Build와 Submit을 통해 안전하게 배포할 수 있도록 지원합니다. 구글 플레이와 애플 앱스토어 실제 운영 경험에서 얻은 18개 이상의 사전 검증 게이트를 제공하여 알려진 심사 거절 사유를 사전에 방지합니다. 프로덕션 트랙 자동 배포를 원천 차단하고 내부 트랙 및 TestFlight 배포만을 허용하여 배포 안전성을 극대화했습니다.
