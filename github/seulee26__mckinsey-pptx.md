Claude Code에서 동작하는 플러그인으로, 한국어 채팅 명령어 한 줄만으로 맥킨지 스타일의 고퀄리티 파워포인트 파일을 자동 생성합니다. 엑셀, 워드, PDF 등의 원본 파일을 읽어 40개의 전문 템플릿 중 적절한 차트와 매트릭스를 조합하여 완성된 데크를 출력하며, 코딩 지식 없이도 대화를 통해 슬라이드를 수정하고 다듬을 수 있습니다.
