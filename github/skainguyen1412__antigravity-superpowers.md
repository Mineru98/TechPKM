Claude Code용으로 개발된 Superpowers 워크플로우 시스템을 Antigravity 플랫폼에 포팅한 프로젝트입니다. 브레인스토밍, 계획 수립, TDD, 코드 리뷰 등 AI 코딩 보조 도구에 구조화된 개발 주기를 제공하며, 원본의 14개 스킬 중 12개를 그대로 유지하고 나머지 2개를 순차 실행 방식으로 통합했습니다. 단일 명령어로 프로젝트에 프로필을 초기화하여 Antigravity 환경에서 즉시 사용할 수 있습니다.
