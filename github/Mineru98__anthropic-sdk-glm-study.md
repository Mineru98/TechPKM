Claude Agent SDK의 서브에이전트 구조를 GLM(z.ai) 백엔드에서 실행해 보는 학습용 프로젝트입니다. 경량 프롬프트 체이닝부터 다단계 오케스트레이터-워커 패턴까지, 다양한 산업 도메인을 적용한 멀티에이전트 샘플 12종을 제공합니다. Bun 런타임 기반으로 동작하며, 3계층 루브릭 평가 시스템과 TUI 및 데모 녹화 파이프라인을 포함하고 있습니다.
