OpenCode를 위한 오픈소스 플러그인으로, Claude, GPT, Kimi, GLM 등 다양한 AI 모델을 작업 유형에 따라 자동으로 오케스트레이션하여 에이전트 기반 개발 환경을 제공합니다. 단일 명령어(`ultrawork`)로 전문 에이전트 팀을 병렬 실행하며, 해시 기반 편집 도구와 LSP/AST-Grep 통합으로 코드 수정의 안정성과 정밀도를 극대화합니다. Claude Code와 완전 호환되며, 기존 설정이나 MCP를 그대로 사용할 수 있는 것이 핵심 특징입니다.
