TypeScript 컴파일러를 기반으로 플러그인 기능과 타입 안전한 실행 환경을 제공하는 `ttsc` 도구 체인입니다. 기존 `tsc`의 드롭인 대체제로 동작하며, 타입 검사 단계에서 린트 및 포맷팅을 수행하고 요구사항 추적(Evidence)과 AI 에이전트용 컴파일러 지식 그래프를 기본적으로 지원합니다. 다양한 번들러 및 에디터 통합을 통해 개발 생산성과 코드 품질을 동시에 향상시키는 것을 목표로 합니다.
