Claude Code 심화 워크샵을 위해 제작된 3일 차량 한국어 기술 커리큘럼입니다. 총 850장의 슬라이드로 구성된 6개 챕터 PDF와 함께, 코드가 포함된 슬라이드를 독립적인 마크다운 파일로 추출한 502개의 코드 스니펫을 제공합니다. Anthropic Direct, Amazon Bedrock, Vertex AI 세 가지 인증 경로를 다루며, Python과 TypeScript 예제를 통합 지원하고 각 스니펫에는 한국어 발표자 노트가 포함되어 있어 별도의 빌드 과정 없이도 즉시 학습 및 발표에 활용할 수 있습니다.
