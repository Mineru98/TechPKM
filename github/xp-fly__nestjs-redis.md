ioredis를 기반으로 하는 NestJS의 Redis 모듈입니다. 동기 및 비동기 방식의 설정을 지원하며, 여러 개의 Redis 연결을 데코레이터를 통해 손쉽게 주입하고 관리할 수 있는 기능을 제공합니다.
