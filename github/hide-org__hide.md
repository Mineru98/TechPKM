Hide는 코드 저장소를 위한 컨테이너화된 개발 환경을 구성하고, 코딩 에이전트가 이와 상호작용할 수 있는 API를 제공하는 헤드리스 IDE 프로젝트입니다. Docker 기반 런타임과 SDK로 구성되며, Langchain 등 인기 프레임워크용 사전 빌드 툴킷이나 커스텀 툴킷을 활용할 수 있습니다. 이 저장소는 Hide Runtime의 소스 코드를 포함하고 있습니다.
