로컬 환경에서 동작하는 에이전트 기반 HTML 에디터로, Claude Code, Cursor Agent 등 8종의 코딩 에이전트 CLI를 자동 감지하여 별도의 API 키 없이 75개의 스킬 템플릿으로 고품질 단일 파일 HTML을 생성합니다. 잡지 기사, 키노트 덱, 포스터, 웹 프로토타입 등 9가지 출력 형식을 지원하며, 생성된 결과물을 위챗, X(트위터), 지후 등으로 원클릭 내보내기 할 수 있습니다. 실시간 스트리밍 렌더링과 샌드박스 iframe 미리보기를 통해 AI가 작성하는 과정을 안전하게 모니터링할 수 있습니다.
