NestJS를 활용하여 소켓 통신 기반 채팅 기능을 구현하는 방법을 보여주는 예제 프로젝트입니다. 실시간 양방향 통신이 필요한 애플리케이션 개발 시 기본적인 구조와 설정을 참고할 수 있도록 구성되었습니다. 개발 및 프로덕션 환경 실행을 위한 다양한 npm 스크립트를 제공합니다.
