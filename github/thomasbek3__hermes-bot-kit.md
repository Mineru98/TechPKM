Hermes Desktop 환경에서 봇과의 대화를 문자 메시지 느낌으로 개선하고, 봇이 작업하는 컴퓨터 화면을 실시간으로 모니터링할 수 있게 해주는 플러그인 키트입니다. 채팅 버블 UI, 원격 데스크톱 뷰어, 봇의 답변 스타일을 SMS 형식으로 변환하는 에이전트 플러그인으로 구성되어 있으며, 빌드 과정 없이 단일 명령어로 손쉽게 설치할 수 있습니다.
