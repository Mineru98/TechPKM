WebMCP는 웹 애플리케이션의 클라이언트 측 기능을 AI 에이전트가 호출할 수 있는 '도구'로 노출하기 위한 웹 플랫폼 API 제안입니다. 기존 백엔드 중심의 MCP 통신이 가지는 UI 단절 및 상태 동기화 문제를 해결하고, 사용자와 에이전트가 브라우저 내에서 동일한 컨텍스트를 공유하며 협업할 수 있는 환경을 제공합니다. 이를 통해 개발자는 기존 JavaScript 코드를 재사용하여 에이전트가 웹 콘텐츠를 더 직접적이고 신뢰성 있게 조작할 수 있도록 지원합니다.
