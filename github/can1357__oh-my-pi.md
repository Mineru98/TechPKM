이 프로젝트는 터미널 환경에서 작동하는 고성능 AI 코딩 에이전트 'oh-my-pi'로, 복잡한 소프트웨어 개발 워크플로우를 자동화하고 보조합니다. Rust로 작성된 네이티브 엔진을 사용하여 빠른 파일 검색, 셸 실행, LSP 통합을 제공하며, 다양한 AI 모델과 공급자를 지원하여 사용자가 선호하는 도구와 유연하게 연동할 수 있습니다. 또한 대화형 세션 관리, 서브에이전트를 통한 병렬 작업, 그리고 TypeScript 기반의 확장 기능을 통해 개발 생산성을 극대화하도록 설계되었습니다.
