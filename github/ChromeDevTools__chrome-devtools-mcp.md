AI 코딩 에이전트가 실행 중인 Chrome 브라우저를 제어하고 검사할 수 있도록 지원하는 MCP(Model Context Protocol) 서버입니다. Puppeteer를 기반으로 신뢰할 수 있는 브라우저 자동화를 제공하며, Chrome DevTools를 활용해 성능 추적, 네트워크 요청 분석, 디버깅 등의 고급 작업을 수행할 수 있습니다. Claude, Cursor, Copilot 등 다양한 MCP 클라이언트와 손쉽게 연동하여 사용할 수 있습니다.
