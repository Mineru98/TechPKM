iii는 API 프레임워크, 작업 큐, 크론 스케줄러 등 여러 백엔드 도구를 함수, 트리거, 워커라는 세 가지 기본 요소로 통합하는 실행 엔진입니다. 하나의 설정 파일과 프로세스로 내구성 있는 오케스트레이션과 다언어 상호 운용성을 제공하며, 실시간 발견, 확장 및 관찰이 가능한 시스템 특성을 갖추고 있습니다. Node.js, Python, Rust SDK를 통해 손쉽게 통합할 수 있어 백엔드 아키텍처의 복잡성을 크게 줄여줍니다.
