Marp 슬라이드 도구의 핵심 변환 엔진으로, Marpit 프레임워크를 기반으로 Markdown을 HTML과 CSS로 변환합니다. 공식 테마, 수식 렌더링(MathJax, KaTeX), 이모지 지원, 슬라이드 자동 크기 조정 등 프레젠테이션 제작에 필요한 고급 기능을 제공합니다.
