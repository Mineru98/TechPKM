React 애플리케이션 개발에 필수적인 커스텀 훅을 대규모로 모아놓은 라이브러리입니다. 센서, UI, 애니메이션, 사이드 이펙트, 생명주기, 상태 관리 등 다양한 도메인의 훅을 제공하여 반복적인 로직 작성을 줄이고 개발 생산성을 높입니다. 기존 libreact 프로젝트를 React Hooks 방식으로 포팅한 결과물입니다.
