Claude Code의 대화, 도구 호출, 하위 에이전트 실행 등을 LangSmith로 추적하는 플러그인입니다. 기존 LangSmith 실행 계층 구조에 중첩하거나, 여러 프로젝트 및 워크스페이스로 동시에 추적 데이터를 복제할 수 있는 고급 기능을 제공합니다. LLM 애플리케이션의 디버깅과 모니터링을 위해 Claude Code 환경에 쉽게 통합할 수 있도록 설계되었습니다.
