Gajae-Code(gjc)는 요구사항 인터뷰, 계획 수립, 실행 및 검증으로 이어지는 핵심 루프에 집중한 자율 코딩 에이전트 하네스입니다. tmux 기반의 세션 관리와 Git worktree 격리를 통해 안전하고 내구성 있는 작업 환경을 제공하며, Claude Code나 Codex CLI 등 다른 코딩 에이전트와 함께 외부 실행기로서 유연하게 연동될 수 있습니다. 복잡한 기능 확장보다는 작은 워크플로우를 더욱 견고하게 개선하는 데 중점을 둔 실험적 프로젝트입니다.
