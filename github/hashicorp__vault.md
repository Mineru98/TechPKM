Vault는 HashiCorp에서 개발한 비밀 정보(Secret) 관리 도구로, API 키, 비밀번호, 인증서 등 접근을 엄격히 통제해야 하는 데이터를 안전하게 저장하고 관리한다. 암호화된 저장소, 동적 시크릿 생성, 임대 및 자동 폐기, 상세 감사 로그 등의 핵심 기능을 제공하며, 통합된 인터페이스를 통해 다양한 시스템의 시크릿 접근을 일원화한다.
