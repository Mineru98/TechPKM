Himalaya는 Rust로 작성된 명령줄(CLI) 이메일 관리 도구로, 셸 명령을 통해 상태 비저장 방식으로 메일을 다룰 수 있습니다. IMAP, SMTP, ManageSieve, JMAP, Gmail REST API, Microsoft Graph는 물론 Maildir, mbox 같은 로컬 백엔드까지 지원하며, TOML 기반 멀티 계정 설정과 자동 디스커버리 마법사를 제공합니다. aerc나 mutt 같은 TUI와 달리 이벤트 루프 없이 스크립트 및 자동화 환경에 적합하며, JSON 출력과 프록시·TLS 지원도 갖추고 있습니다.
