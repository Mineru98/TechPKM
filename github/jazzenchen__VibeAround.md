Claude Code, Codex CLI, Gemini CLI 등 다양한 AI 코딩 에이전트를 하나의 통합 허브에서 관리하고 실행할 수 있도록 돕는 올인원 플랫폼입니다. 에이전트 간에 호환되지 않는 API 프로토콜을 자동으로 변환하는 브릿지 기능을 제공하며, 데스크톱, CLI, 웹 브라우저, 메신저 앱 등 다양한 환경에서 동일한 세션을 이어서 작업할 수 있는 원격 세션 연속성을 지원합니다. 로컬 우선 보안 모델을 채택하여 에이전트 실행과 자격 증명을 사용자의 컴퓨터에 안전하게 유지합니다.
