의존성과 프레임워크 없이 동작하는 텍스트 줄바꿈 균형 라이브러리입니다. react-wrap-balancer의 핵심 이진 탐색 알고리즘을 그대로 포팅하여, 별도의 빌드 과정 없이 단일 스크립트 태그로 제목의 마지막 줄에 단어가 고립되는 현상을 방지합니다. 브라우저 네이티브 CSS를 우선 지원하며, 리사이즈나 콘텐츠 변경 시 자동으로 재균형을 수행합니다.
