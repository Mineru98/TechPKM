TypeScript와 ES6 환경에서 일반 자바스크립트 객체와 클래스 인스턴스 간의 변환을 지원하는 라이브러리입니다. 데코레이터를 기반으로 직렬화 및 역직렬화를 세밀하게 제어할 수 있어, 프론트엔드와 백엔드 양쪽에서 API 모델을 다룰 때 유용하게 활용됩니다. 중첩 객체 처리, 버전 관리, 그룹 기반 노출 제어 등 다양한 고급 기능을 제공합니다.
