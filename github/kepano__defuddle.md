Defuddle는 웹 페이지에서 불필요한 요소를 제거하고 주요 콘텐츠만을 추출하여 깔끔한 HTML이나 마크다운으로 변환해주는 라이브러리입니다. Mozilla Readability를 대체할 수 있으며, 모바일 스타일을 활용한 콘텐츠 추출, 수학 및 코드 블록의 일관된 처리, 다양한 메타데이터 지원이 특징입니다. 주로 Obsidian 웹 클리퍼(Web Clipper)를 위해 개발되었지만, 브라우저뿐만 아니라 Node.js 환경과 CLI에서도 사용할 수 있습니다.
