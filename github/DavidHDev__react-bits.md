React Bits는 215개 이상의 무료 애니메이션 React 컴포넌트와 배경을 제공하는 오픈소스 UI 라이브러리입니다. 텍스트 애니메이션, 배경 효과, 컴포넌트 등 카테고리별로 구성되어 있으며, JavaScript/TypeScript와 CSS/Tailwind 조합으로 선택해 shadcn CLI, jsrepo, 또는 직접 복사를 통해 손쉽게 프로젝트에 추가할 수 있습니다. MCP 서버 연동을 통해 Claude Code, Cursor 등 AI 에이전트가 컴포넌트를 직접 찾아 추가할 수도 있습니다.
