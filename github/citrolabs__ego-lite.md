ego lite는 사용자와 AI 에이전트가 하나의 브라우저를 함께 사용할 수 있도록 설계된 macOS용 브라우저입니다. 에이전트는 각자 격리된 Space에서 병렬로 브라우저 작업을 수행하고, 사용자의 탭과 로그인 데이터는 그대로 유지되며, `ego-browser` 스킬을 통해 Claude Code, Codex, Cursor 등 어떤 에이전트 CLI로도 제어할 수 있습니다. CLI 기반 자동화 대신 코드 기반 접근 방식을 사용해 복잡한 작업을 최대 2.5배 빠르게, 더 적은 토큰으로 처리할 수 있습니다.
