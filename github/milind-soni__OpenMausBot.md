OpenMausBot은 Grok Bot의 오픈소스 대안으로, 채팅 앱 안에서 Claude, Codex, Grok CLI 기반의 여러 AI 에이전트 봇을 연락처처럼 대화하며 사용할 수 있는 로컬 퍼스트 데스크톱 애플리케이션입니다. 각 봇은 자체 모델, 클라우드 컴퓨터, 연결된 앱을 가지며, 승인 카드를 통해 위험 작업을 사용자가 통제할 수 있습니다. Apache 2.0 라이선스로 공개되어 있으며 macOS, Windows, Ubuntu를 지원합니다.
