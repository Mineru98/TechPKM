Hermes Desktop 환경에서 에이전트가 사용하는 원격 컴퓨터의 데스크톱을 실시간으로 모니터링하고 제어할 수 있는 플러그인입니다. VNC 및 WebSockets를 기반으로 클라우드와 로컬 머신을 하나의 드롭다운으로 전환하여 관리하며, 필요에 따라 H.264 하드웨어 인코딩 고성능 스트리밍도 지원합니다. 또한 선택적 에이전트 플러그인을 통해 봇이 직접 셸 명령을 실행하거나 GUI를 조작하는 등 컴퓨터를 직접 다루는 기능을 제공합니다.
