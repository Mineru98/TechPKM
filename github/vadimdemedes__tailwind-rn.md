React Native 프로젝트에서 Tailwind CSS를 사용할 수 있도록 지원하는 라이브러리입니다. Tailwind의 CSS 출력을 JSON으로 변환하여 제공하므로, 항상 최신 스타일을 반영할 수 있습니다. JIT 모드, 반응형 브레이크포인트, 다크 모드 등의 핵심 기능을 지원합니다.
