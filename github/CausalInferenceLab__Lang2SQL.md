Lang2SQL은 자연어 쿼리를 최적화된 SQL 문으로 변환하고, 이를 시각화하는 오픈소스 도구입니다. LangGraph와 DataHub를 기반으로 복잡한 데이터베이스 스키마에 대한 깊은 지식 없이도, 의미론적 검색과 메타데이터 활용을 통해 효율적으로 SQL을 생성하고 인사이트를 도출할 수 있는 환경을 제공합니다.
