구글의 머티리얼 디자인 시스템을 독자적으로 구현한 포괄적인 React 컴포넌트 라이브러리입니다. 10년 이상의 개발 기간 동안 수많은 오픈소스 기여자에 의해 엄격하게 검증되어 전 세계 주요 제품 팀에서 신뢰받고 있습니다. 고급 사용 사례를 위한 복잡한 컴포넌트 제품군인 MUI X를 통해 핵심 기능을 확장할 수 있습니다.
