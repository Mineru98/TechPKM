DeepSpeed는 대규모 딥러닝 모델의 효율적인 훈련과 추론을 가능하게 하는 PyTorch 기반의 라이브러리입니다. 메모리 최적화 기술인 ZeRO, 3D 병렬화, 오프로딩 등의 시스템 혁신을 통해 수천억 개의 파라미터를 가진 모델을 훈련할 수 있도록 지원합니다. Hugging Face Transformers나 MosaicML 등 주요 프레임워크와 통합되어 거대 언어 모델(LLM) 개발 생태계에서 널리 활용됩니다.
