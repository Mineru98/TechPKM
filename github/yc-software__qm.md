슬랙과 웹에서 동작하는 스타트업을 위한 멀티플레이어 AI 에이전트 하네스입니다. 사용자마다 격리된 워크스페이스를 제공하며, 채널이나 프로젝트에서의 협업, 개인 및 공유 메모리, 내부 웹 앱 구축 등 다양한 업무를 지원합니다. 오픈소스 성격을 띠며 다양한 모델과 하네스(Pi, OpenCode, Claude Code 등)를 유연하게 교체하여 사용할 수 있도록 설계되었습니다.
