Halo Above the Clouds는 스위스 베른 알프스의 두 설산 봉우리 사이에 매달린 콘크리트 링(ring) 레스토랑을 실시간 Three.js(WebGL2) 씬으로 구현한 프로젝트이다. 실제 고도 데이터, 볼류메트릭 클라우드, 베이크된 스카이 돔, 약 11만 개의 마을 조명을 활용해 블루 아워의 풍경을 재현하며, 동일 씬에서 렌더링한 45초 드론 영상도 제공한다. 이 씬은 AI 생성 참조 이미지들을 기반으로 여러 에이전트가 병렬로 작업하여 만들어졌다.
