OpenAI Agents SDK의 JavaScript/TypeScript 버전으로, 다중 에이전트 워크플로우를 구축하기 위한 경량화된 프레임워크입니다. 에이전트 간 작업 위임, 샌드박스 환경 지원, 가드레일, 휴먼 인 더 루프 등 핵심 기능을 제공하며 OpenAI API뿐만 아니라 다양한 프로바이더를 사용할 수 있도록 설계되었습니다. Node.js, Deno, Bun 등의 최신 JavaScript 런타임 환경에서 실행할 수 있습니다.
