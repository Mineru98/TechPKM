AI 에이전트가 생성하는 프론트엔드 UI의 퀄리티를 높이기 위한 이식 가능한 에이전트 스킬 모음입니다. 레이아웃, 타이포그래피, 모션, 간격 등을 조절하여 획일적이고 평범한 결과물을 방지하며, 이미지 생성부터 코드 구현까지 연결하는 워크플로우도 제공합니다. 프레임워크에 종속되지 않아 ChatGPT, Codex, Cursor, Claude Code 등 다양한 AI 코딩 에이전트와 함께 사용할 수 있습니다.
