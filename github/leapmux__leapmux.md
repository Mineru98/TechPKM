LeapMux는 여러 Claude Code 인스턴스를 중앙 집중식 웹 인터페이스에서 실행하고 관리할 수 있는 AI 코딩 에이전트 멀티플렉서 플랫폼입니다. Go로 작성된 Hub, Worker 아키텍처를 기반으로 SolidJS 프론트엔드를 제공하며, 개발자는 하나의 화면에서 다양한 백엔드와 워크스페이스의 AI 에이전트를 병렬로 제어하고 터미널 및 파일 시스템에 상호작용할 수 있습니다.
