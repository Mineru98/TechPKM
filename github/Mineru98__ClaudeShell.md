불안정한 네트워크 환경에서도 안정적인 원격 터미널 접속을 제공하기 위해 개발된 웹 기반 터미널 에뮬레이터입니다. React와 Express, WebSocket(node-pty)을 기반으로 구축되었으며, PWA 지원 및 세션 유지 기능을 통해 어디서나 개발 생산성을 유지할 수 있도록 지원합니다. 모바일 친화적 반응형 디자인과 GitHub 스타일의 다크 테마를 적용하여 편리한 터미널 경험을 제공합니다.
