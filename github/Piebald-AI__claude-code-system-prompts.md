이 저장소는 Anthropic의 **Claude Code v2.1.31** 버전에 적용된 전체 시스템 프롬프트와 시스템 리마인더, 내장 도구 설명 등을 포함하여 110개 이상의 문자열을 추출하고 관리합니다. 단일 문자열이 아닌 환경별 조건부 설정, 서브 에이전트, 유틸리티 기능 등으로 세분화된 복잡한 프롬프트 구조를 파악하는 데 필수적인 참고 자료입니다. 사용자는 **tweakcc**를 활용하여 이 문서를 기반으로 자신만의 Claude Code 설치 환경을 세부적으로 커스터마이징할 수 있습니다.
