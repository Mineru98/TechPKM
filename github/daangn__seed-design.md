Seed Design는 당근(Danggeun Market)에서 개발한 모놀리식 디자인 시스템으로, React 컴포넌트 라이브러리, CSS 기반 라이브러리, 통합 도구를 포함합니다. Headless 컴포넌트와 StackFlow 연동을 지원하며, Figma와의 연동을 통해 디자인와 개발 간의 생산성을 높이는 것을 목표로 합니다. Rootage 및 Qvism과 같은 하위 패키지와 통합 생태계를 구성하여 웹 서비스 개발에 필요한 일관된 UI/UX 경험을 제공합니다.
