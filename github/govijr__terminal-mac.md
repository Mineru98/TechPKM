terminal-mac은 Apple silicon Mac에서 Apple Virtualization으로 별도의 macOS 게스트 VM을 실행하고, 이를 터미널에서 스트리밍하여 확인·제어할 수 있는 도구입니다. Kitty, iTerm2, Ghostty 같은 터미널 뷰어로 게스트 화면을 보여주고, MCP 도구(screenshot, click, type 등)를 통해 AI 에이전트가 호스트에 영향을 주지 않고 가상 Mac에서 컴퓨터 조작을 수행할 수 있게 합니다. Claude Code 등 MCP 클라이언트와 스킬 설치를 지원하며, 격리된 입력·화면 전송 구조로 안전한 에이전트 컴퓨터 사용 환경을 제공합니다.
