Codex CLI와 Claude Code 환경에서 재사용할 수 있는 프롬프트 자산(스킬, 커맨드, 룰)을 모아둔 저장소입니다. 커밋 메시지 생성, 브라우저 자동화, 프롬프트 설계 등 다양한 작업을 위한 스킬을 제공하며, GitHub URL을 통한 스킬 자동 설치 기능을 지원합니다. 또한 프론트엔드 프로젝트를 위한 Clean Architecture 및 TypeScript 등의 규칙 세트를 포함하여 일관된 개발 컨벤션을 유지할 수 있도록 돕습니다.
