OpenTag은 기존 협업 플랫폼(Slack, GitHub, GitLab 등)의 스레드를 로컬에서 실행되는 코딩 에이전트(Codex, Claude Code 등)와 연결하여, 관리 가능하고 감사 가능한 작업 루프로 변환하는 로컬 우선 도구입니다. 컨텍스트를 큐레이션하고 권한을 검사한 뒤 에이전트를 실행하며, 그 결과물과 안전한 후속 조치를 원래의 스레드로 반환합니다. 클라우드 서비스 없이 로컬 환경에서 완전하게 작동하여 개인정보와 보안을 강화합니다.
