이 프로젝트는 Expo 앱 개발을 위한 공식 기본 템플릿으로, `create-expo-app`을 통해 생성됩니다. 파일 기반 라우팅(File-based routing)을 지원하며, 개발 서버 시작 시 Android 에뮬레이터, iOS 시뮬레이터 또는 Expo Go를 통해 앱을 바로 실행하고 테스트할 수 있는 환경을 제공합니다. 또한 프로젝트 초기화 명령어를 통해 스타터 코드를 정리하고 새로운 개발을 즉시 시작할 수 있는 구조로 되어 있습니다.
