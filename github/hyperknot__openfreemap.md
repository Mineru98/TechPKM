웹사이트와 애플리케이션에 OpenStreetMap 기반의 맵 타일을 무료로 표시할 수 있도록 지원하는 오픈소스 프로젝트입니다. 별도의 타일 서버 없이 Btrfs 파티션 이미지와 하드 링크를 활용하여 고성능으로 벡터 타일을 제공하는 것이 핵심 특징입니다. 직접 서버를 구축해 호스팅하거나, 등록 및 API 키 없이 무료로 제공되는 퍼블릭 인스턴스를 사용할 수 있습니다.
