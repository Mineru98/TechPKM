AI 에이전트와 터미널 환경에서 Unity 에디터를 직접 제어할 수 있는 경량화된 CLI 도구입니다. 별도의 서버 구축이나 복잡한 프로토콜 설정 없이 단일 바이너리와 유니티 패키지만으로 HTTP 통신을 통해 에디터 제어, C# 코드 실행, 콘솔 로그 확인, 테스트 실행 등 다양한 작업을 수행할 수 있으며, 커스텀 툴 작성을 통한 기능 확장도 지원합니다.
