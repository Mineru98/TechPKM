Claude Code를 비롯한 AI 코딩 에이전트의 기능을 확장하고 업무 효율성을 높이기 위해 설계된 규범적(Opinionated) 스킬 및 에이전트 모음입니다. 개발, 문서화, 기획, 커뮤니케이션 등 다양한 영역에 걸쳐 재사용 가능한 스킬, 슬래시 명령어, 전문화된 에이전트를 제공하며, Agent Skills 형식을 따릅니다.
