Spring Data R2DBC를 사용하여 리액티브 데이터베이스 드라이버를 통해 관계형 데이터베이스에 데이터를 저장하고 조회하는 애플리케이션 구축 방법을 안내하는 가이드입니다. 메모리 기반 H2 데이터베이스를 활용해 고객(Customer) 엔티티를 다루며, 구체적인 리포지토리 구현 없이도 리액티브 CRUD 작업을 수행하는 핵심 특징을 보여줍니다.
