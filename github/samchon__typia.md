순수 TypeScript 타입을 컴파일 단계에서 분석하여 런타임 검증 함수로 변환해 주는 고성능 트랜스포머 라이브러리입니다. 별도의 스키마 정의 없이 타입 하나만으로 초고속 검증, JSON 직렬화, LLM 함수 호출 하니스, Protocol Buffers 인코딩 및 디코딩, 랜덤 데이터 생성 등의 기능을 제공합니다. 기존 라이브러리 대비 월등한 성능 향상과 타입 안전성을 보장하여 NestJS, tRPC 등 다양한 생태계와 통합하여 활용할 수 있습니다.
