오철칙(Iron Laws)은 AI로 작성된 코드의 보안 취약점과 구조적 문제를 점검하는 파이썬 기반 정적 분석 CLI 도구입니다. 행안부 SW 개발보안 가이드 49개 항목과 AI 특유의 나쁜 습관(하드코딩된 비밀, 삼킨 예외, 타입 회피 등)을 쉬운 설명과 함께 찾아내고, AI 코딩 도구에 붙여넣을 수정 지시문을 생성하며, AI 수정 결과의 검증·승인 근거 관리, 의존성 취약점 점검, SBOM 생성, 구조 진단, MCP 서버 및 CI 연동을 지원합니다.
