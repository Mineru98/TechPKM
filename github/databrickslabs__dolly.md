Databricks가 개발한 상업적 사용이 허가된 명령어 수행 대형 언어 모델입니다. EleutherAI의 Pythia-12b를 기반으로, 약 1만 5천 개의 명령어-응답 데이터셋을 통해 파인튜닝되었습니다. 최첨단 모델은 아니지만, 기반 모델에서는 볼 수 없었던 놀랍도록 고품질의 명령어 수행 능력을 보여줍니다.
