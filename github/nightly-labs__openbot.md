OpenBot은 로컬 우선(local-first) 방식으로 동작하는 데스크톱 AI 에이전트 워크스페이스입니다. Codex, Claude Code, Grok CLI, OpenCode, Gemini, Cursor, Cline 등 다양한 AI 에이전트를 지원하며, 각 에이전트에게 독립적인 작업 공간과 대화 세션을 제공합니다. 로컬 메시지 큐, 파일 전송, 내장 브라우저, 에이전트 간 메시징을 하나의 데스크톱 앱에서 처리하며, macOS·Windows·Linux와 Docker, 셀프호스팅 서버 환경을 지원합니다.
