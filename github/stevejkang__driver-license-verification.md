안전운전단말기와 전자민원 포털의 데이터를 활용하여 운전면허증 진위 여부를 확인하는 비공식 크롤러 API 서비스입니다. Node.js 환경에서 실행되며, 이름과 생년월일, 면허번호 등을 입력받아 유효성 검증 결과를 JSON 형태로 반환합니다.
