Apache Magpie는 Claude Code, Codex, Copilot 등 기존에 사용 중인 AI 에이전트에 설치하는 검증된 스킬 모음으로, 오픈소스 프로젝트 운영의 반복 작업(이슈·PR 트리아지, 코드 리뷰, 기여자 멘토링, 보안 보고서 처리 등)을 지원합니다. 모든 결과물은 에이전트가 초안만 작성하고 사람이 게시하는 방식으로 자율 모드가 없으며, 파일시스템·네트워크 샌드박스와 셸 명령 사전 검사 가드로 에이전트를 격리합니다. Apache-2.0 라이선스의 벤더 중립적 프로젝트로, 텔레메트리는 기본적으로 비활성화되어 있습니다.
