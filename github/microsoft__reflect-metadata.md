ECMAScript 메타데이터 리플렉션 API의 폴리필을 제공하는 패키지입니다. 클래스 및 멤버에 메타데이터를 선언적 또는 명령적으로 정의하고 조회할 수 있는 기능을 지원하며, 의존성 주입이나 런타임 타입 검사 등의 주요 사용 사례를 해결합니다. 현재는 표준화 제안이 중단되었으나, TypeScript의 레거시 `experimentalDecorators` 환경을 사용하는 프로젝트를 계속 지원합니다.
