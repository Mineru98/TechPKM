Chromex는 로컬 네이티브 브릿지를 통해 Chrome 브라우저와 OpenAI Codex를 연결하는 MV3 사이드 패널 어시스턴트입니다. 현재 웹페이지, 탭, 파일, 음성, 이미지 등의 브라우저 맥락을 활용하여 대화 및 요약, 이미지 편집, 브라우저 제어 등의 작업을 수행할 수 있습니다. API 키나 인증 토큰을 확장 프로그램 저장소에 저장하지 않도록 설계되어 보안과 개인정보 보호를 강조하는 것이 특징입니다.
