블로그 등에 사용할 고품질의 다이어그램을 60초 만에 생성해 주는 Claude Code 스킬입니다. 아키텍처, 순서도, 타임라인 등 13가지 유형을 지원하며, 웹사이트 URL만 입력하면 브랜드 색상과 폰트를 자동 추출하여 일관된 편집용 디자인을 적용합니다. 별도의 빌드 과정이나 외부 이미지 없이 순수 HTML과 SVG로 구성되어 브라우저에서 바로 확인할 수 있습니다.
