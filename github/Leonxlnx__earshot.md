earshot은 AI 코딩 에이전트가 소리를 "들을" 수 있도록 지원하는 CPU 기반 로컬 오디오 분석 및 생성 도구입니다. 소리를 텍스트로 설명하고, 설명 일치도를 판단하며, 긴 녹음에서 최적의 순간을 찾고, 실제 녹음과 코드 합성 음원을 구별하는 CLI, Python API, MCP 서버를 제공합니다. 또한 코드로 직접 사운드를 합성하고 청취 피드백으로 개선하는 forge, 녹음물을 코드 레시피로 변환하는 fit, 영상용 사운드 뱅크와 킷 등으로 에이전트가 스스로 고품질 사운드를 만들고 검증할 수 있게 합니다.
