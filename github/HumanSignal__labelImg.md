Pascal VOC, YOLO, CreateML 형식을 지원하는 그래픽 기반의 이미지 어노테이션 도구입니다. 파이썬과 Qt로 작성되었으며, 객체 탐지 모델 학습을 위해 이미지에 바운딩박스를 쉽고 빠르게 그려줍니다. 현재는 개발이 중단되며 후속 프로젝트인 Label Studio로 통합되었습니다.
