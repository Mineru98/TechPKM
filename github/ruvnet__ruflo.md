Claude Code를 위한 엔터프라이즈급 다중 에이전트 AI 오케스트레이션 플랫폼입니다. 100개 이상의 전문 에이전트를 스웜 형태로 배포하고, SONA 자가 학습 및 HNSW 벡터 검색을 통해 작업 패턴을 기억하며 지능적으로 라우팅합니다. 내결함성 합의 알고리즘, WASM 기반 코드 변환, 그리고 다양한 LLM 제공자 연동을 통해 API 비용을 최적화하는 것이 핵심 특징입니다.
