이 프로젝트는 Claude Code 및 Cowork를 위해 설계된 'PM Skills Marketplace'로, 65개 이상의 제품 관리(PM) 스킬과 36개의 연결된 워크플로우를 제공합니다. 발견(Discovery)에서 전략, 실행, 출시 및 성장에 이르는 전 과정을 아우르는 검증된 PM 프레임워크를 AI 인터페이스에 통합하여, 단순한 텍스트 생성이 아닌 구조화되고 체계적인 제품 의사결정을 지원하는 것이 핵심 목적입니다.
