Node.js, Express, Mongoose를 기반으로 RESTful API를 빠르게 구축하기 위한 보일러플레이트 프로젝트입니다. 단일 명령어 실행만으로 JWT 인증, 요청 유효성 검사, 테스트, CI/CD, Docker 지원 등 프로덕션 환경에 필요한 다양한 기능이 완비된 애플리케이션을 설정할 수 있습니다. 체계적인 프로젝트 구조와 중앙 집중식 에러 처리, Swagger 기반 API 문서화를 제공하여 안정적이고 확장 가능한 백엔드 개발을 지원합니다.
