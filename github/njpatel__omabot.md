Omabot은 Omarchy 셸의 바(bar)에서 Grok Bot 봇 목록을 보여주는 플러그인이다. Grok Bot이 디스크에 저장하는 상태 파일을 읽어(네트워크 사용 없음) 봇들을 앱에서와 동일한 모양과 색으로 렌더링하며, 응답 대기 중인 봇의 등장 애니메이션, 패널의 안내 메시지·읽지 않음 배지, 포인터를 따라다니는 눈 등의 인터랙션을 제공한다. 설정 없이 `python3`와 Grok Bot 데스크톱 앱만 있으면 동작한다.
