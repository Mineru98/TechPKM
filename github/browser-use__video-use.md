Claude Code와 같은 AI 에이전트와 대화하여 원본 영상을 자동으로 편집해 주는 오픈소스 도구입니다. 불필요한 공백이나 군더더기를 제거하고, 자막 생성, 색보정, 애니메이션 오버레이 등의 작업을 수행하며, 최종 결과물을 자체 평가하는 파이프라인을 제공합니다. 프리셋이나 메뉴 없이 텍스트 명령만으로 다양한 형태의 영상을 제작할 수 있는 것이 특징입니다.
