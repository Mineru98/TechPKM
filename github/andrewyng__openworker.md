데스크톱 환경에서 실행되어 실제 업무 결과물을 완성해 주는 오픈소스 AI 코워커입니다. 문서 작성, 캘린더 정리, 슬랙 답변 등의 작업을 25개 이상의 연동 도구와 결합하여 자동으로 수행하며, 중요한 실행 전에는 반드시 사용자 승인을 요구합니다. 로컬 우선 방식으로 동작하여 데이터를 기기에 안전하게 보관하고, OpenAI, Anthropic, Ollama 등 다양한 모델 제공자를 자유롭게 선택하여 사용할 수 있습니다.
