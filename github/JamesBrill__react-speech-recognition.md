마이크로폰으로 입력된 음성을 텍스트로 변환하여 React 컴포넌트에서 사용할 수 있게 해주는 React 훅 라이브러리입니다. Web Speech API를 기반으로 동작하며, 특정 명령어 인식, 퍼지 매칭, 다국어 지원 등 고급 음성 인식 기능을 제공합니다. 폴리필을 통해 크로스 브라우저 호환성 및 상용 앱 개발 환경을 구축할 수도 있습니다.
