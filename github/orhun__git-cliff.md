Git 히스토리를 기반으로 체인지로그 파일을 자동으로 생성하는 CLI 도구입니다. 컨벤셔널 커밋과 정규식 기반의 커스텀 파서를 지원하며, 설정 파일과 템플릿을 통해 체인지로그의 출력 형식을 자유롭게 세부적으로 조정할 수 있습니다.
