libhangul 기반으로 동작하는 macOS용 오픈 소스 한글 입력기입니다. 두벌식과 세벌식을 비롯한 다양한 자판을 지원하며, 모아치기 기능과 내장 쿼티 자판을 통해 빠르고 편리한 입력 환경을 제공합니다. 가볍고 자유로운 사용을 목표로 BSD와 LGPL 라이선스로 배포됩니다.
