Matt Pocock가 실제 소프트웨어 엔지니어링("바이브 코딩"이 아닌)을 위해 매일 사용하는 AI 코딩 에이전트용 스킬 모음입니다. GSD, BMAD, Spec-Kit 같은 프로세스 통제 방식과 달리 작고, 적응하기 쉽고, 조합 가능한 스킬을 지향하며 어떤 모델에서도 동작합니다. `/grill-me`, `/tdd`, `/diagnosing-bugs`, `/improve-codebase-architecture` 등의 스킬을 통해 에이전트와의 정렬, 공유 언어 구축, 피드백 루프, 코드베이스 설계 같은 소프트웨어 엔지니어링 기본기를 반복 가능한 실천으로 제공합니다.
