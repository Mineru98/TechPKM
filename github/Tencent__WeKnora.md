WeKnora는 Tencent가 공개한 LLM 기반 오픈소스 지식 관리 프레임워크로, 기업 문서 이해, 시맨틱 검색 및 추론을 지원합니다. RAG 기반 질의응답, 멀티스텝 에이전트 작업, 지식 그래프가 포함된 자동 위키의 세 가지 모드가 하나의 지식 베이스 위에서 동작합니다. Docker Compose, Kubernetes, Lite 단일 바이너리 등 다양한 배포 방식을 지원하며, 29개 내장 LLM 벤더, 여러 벡터 DB, IM 채널 및 MCP 통합을 통해 로컬 또는 프라이빗 클라우드에서 유연하게 확장·운영할 수 있습니다.
