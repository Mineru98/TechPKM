GitHub CLI의 확장 프로그램으로, 명령어를 통해 GitHub 이슈나 PR에 이미지 및 파일을 손쉽게 업로드하고 다운로드할 수 있도록 지원합니다. 브라우저 쿠키나 세션 토큰을 활용해 인증을 처리하며, AI 코딩 에이전트와의 연동을 위한 에이전트 스킬 형태로도 제공됩니다. 다양한 출력 포맷(JSON, Markdown 등)을 제공하여 스크립트나 자동화 파이프라인에 유용하게 활용할 수 있습니다.
