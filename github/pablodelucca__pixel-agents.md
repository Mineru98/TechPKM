이 프로젝트는 AI 코딩 에이전트의 활동 상태를 애니메이션 픽셀 아트 캐릭터로 시각화해주는 VS Code 확장 프로그램입니다. Claude Code 터미널을 가상의 사무실 공간에 표현하여, 에이전트가 코드를 작성하거나 사용자 입력을 기다릴 때 캐릭터의 동작으로 실시간 피드백을 제공합니다. 사용자는 내장된 레이아웃 에디터를 활용해 바닥, 벽, 가구를 배치하여 자신만의 업무 환경을 꾸밀 수 있으며, React와 Canvas 2D를 기반으로 한 게임 루프 방식을 통해 캐릭터의 이동과 상태가 렌더링됩니다.
