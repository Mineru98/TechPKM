이 프로젝트는 인기 CLI 에이전트인 Claude Code의 내부 아키텍처를 공개된 참고 자료와 커뮤니티 논의를 바탕으로 심층 분석한 학습 및 연구 저장소입니다. 핵심 에이전트 루프, 40개 이상의 도구 시스템, 권한 관리, 멀티 에이전트 및 스웜 아키텍처, 컨텍스트 압축, MCP 연동 등 프로덕션급 AI 에이전트 하네스를 구성하는 12가지 진보적 메커니즘을 다룹니다. 텔레메트리, 언더커버 모드, 원격 제어 등 숨겨진 기능과 향후 로드맵에 대한 심층 리포트도 4개국어로 제공합니다.
