OpenAI가 발표한 GPT-1 논문의 트랜스포머 언어 모델을 PyTorch로 구현한 프로젝트입니다. TensorFlow로 사전 학습된 가중치를 PyTorch 모델에 로드하는 기능을 제공하며, 분류 작업을 위한 파인튜닝 예제도 포함하고 있습니다. 원본 구조와 최적화 알고리즘을 최대한 동일하게 유지하여 구현의 불일치를 최소화했습니다.
