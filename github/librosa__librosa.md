librosa는 Python 기반의 오디오 및 음악 신호 처리 라이브러리로, 음악 정보 검색(MIR) 시스템을 구축하는 데 필요한 핵심 알고리즘과 도구를 제공한다. PyPI와 conda-forge를 통해 설치할 수 있으며, 튜토리얼과 API 문서가 잘 갖추어져 있다. 학술 인용을 위한 DOI 및 BibTeX 정보도 제공하여 연구 용도로 활용하기 적합하다.
