한글과컴퓨터의 워드프로세서 "한글"의 파일(.hwp)을 읽고 쓰고 조작할 수 있는 Java 기반 오픈소스 라이브러리입니다. Apache-POI를 활용하여 파일의 하부 구조를 파싱하며, 텍스트 추출, 필드 조작, 표 및 이미지 컨트롤 삽입, 문서 병합 등 다양한 문서 편집 기능을 제공합니다. Apache-2.0 라이선스로 자유롭게 사용할 수 있습니다.
