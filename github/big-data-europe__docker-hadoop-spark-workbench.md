Docker Compose를 통해 HDFS와 Spark 환경을 손쉽게 구축할 수 있는 워크벤치입니다. Hive 지원 및 Hue 같은 UI 인터페이스를 제공하여 빅데이터 처리 및 테스트 환경을 빠르게 설정하는 목적으로 설계되었습니다. BDE H2020 EU 프로젝트의 일환으로 개발되었으며, 현재는 더 이상 적극적으로 유지보수되지 않습니다.
