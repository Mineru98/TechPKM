노션 테이블의 상태 컬럼 값을 '발행 요청' 또는 '수정 요청'으로 변경하면, 해당 내용을 자동으로 티스토리 블로그에 업로드 및 수정해 주는 자동화 도구입니다. 셀레니움을 활용해 카카오 연동 티스토리 계정으로 로그인 및 게시물을 관리하며, 포스팅 완료 시 노션 테이블에 URL 링크를 업데이트하고 선택적으로 Gmail 알림을 제공합니다.
