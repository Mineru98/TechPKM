OpenMinis는 Claude, GPT, Gemini 등 다양한 최신 AI 모델을 모바일 기기에서 네이티브로 사용할 수 있게 해주는 오픈소스 개인 AI 에이전트입니다. 기기 내부에서 구동되는 샌드박스 형태의 리눅스 셸, 브라우저 자동화, 시스템 깊숙한 곳과의 통합, 영구 메모리 및 확장 가능한 스킬 시스템을 제공하여 에이전트가 실제 컴퓨터처럼 작동할 수 있도록 지원합니다. 사용자는 직접 API 키를 연동하여 건강 데이터 기록, 일정 관리, 워크플로우 자동화 등 다양한 작업을 개인정보 보호와 프라이버시를 유지하면서 수행할 수 있습니다.
