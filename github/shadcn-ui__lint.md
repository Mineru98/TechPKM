`@shadcn/lint`는 Tailwind 디자인 시스템을 위한 에이전트 우선(agent-first) 린터로, 코딩 에이전트가 디자인 시스템 규칙을 위반했을 때 무엇이 잘못되었고 어떻게 수정해야 하는지 컴포넌트·변형·테마 기반의 구체적인 안내와 함께 알려준다. ESLint와 Oxlint를 지원하며 shadcn/ui 없이도 기존 Tailwind v4 프로젝트에서 React, Svelte, Vue와 함께 사용할 수 있고, 커스텀 메시지·컨트랙트·플레이스홀더 등 프로그래밍 가능한 규칙 구성을 제공한다.
