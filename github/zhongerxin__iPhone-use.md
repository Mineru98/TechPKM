iPhone Use는 WebDriverAgent(WDA)를 통해 USB로 연결된 실제 iPhone을 Codex가 자연어 지시로 조작할 수 있게 하는 Codex 플러그인 및 MCP 서비스 프로젝트입니다. 앱 실행, 화면 읽기, 클릭·스와이프, 한글 포함 텍스트 입력, 리스트 수집 등의 작업을 지원하며, 실시간 화면 미리보기 위젯과 설치·연결 자동 설정 기능을 제공합니다. Xcode 서명이 필요하지만 탈옥이나 별도의 Appium Server 없이 로컬 USB 통신만으로 동작하는 것이 특징입니다.
