DevSpace는 ChatGPT가 로컬 프로젝트 파일을 직접 읽고, 편집하고, 검색하고, 실행할 수 있게 해주는 셀프 호스팅 MCP 서버입니다. Cloudflare Tunnel이나 ngrok 같은 터널과 Owner 비밀번호 승인을 통해 안전하게 로컬 머신에 연결하며, Codex 스타일의 코딩 워크플로우를 ChatGPT에서 구현합니다. 파일 편집, 셸 명령 실행, Git worktree 병렬 세션, AGENTS.md/CLAUDE.md 프로젝트 지침 준수 등의 기능을 제공합니다.
