pi 코딩 에이전트를 위한 확장 슈트로, 모호한 요청을 구조화된 목표로 변환하고 검증자 주도의 지속 가능한 실행 루프를 제공합니다. 서브에이전트 병렬 오케스트레이션, LSP 기반 코드 인텔리전스, MCP 어댑터, 워크스페이스 메모리 등 8개의 번들 확장을 통해 일반 코딩 세션을 체계적인 엔지니어링 워크플로우로 격상시킵니다.
