프레임워크에 종속되지 않는 고성능 JavaScript 애니메이션 라이브러리로, CSS, SVG, 캔버스 등 JavaScript로 접근 가능한 모든 요소를 애니메이션화할 수 있습니다. ScrollTrigger와 같은 강력한 플러그인을 통해 스크롤 기반 애니메이션을 간단한 코드로 구현하며, 반응형 및 접근성 친화적인 애니메이션 제작을 지원합니다. 의존성이 없어 어떤 프로젝트에든 유연하게 적용할 수 있으며, 현재 상업적 이용을 포함하여 완전 무료로 제공됩니다.
