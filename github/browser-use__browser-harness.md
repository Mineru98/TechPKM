LLM 에이전트를 Chrome DevTools Protocol(CDP) 웹소켓을 통해 실제 브라우저에 직접 연결해 주는 경량 하네스 프로젝트입니다. 중간에 복잡한 계층 없이 에이전트가 필요에 따라 헬퍼 코드와 도메인 스킬을 직접 작성하고 실행할 때마다 스스로 개선하도록 설계되었습니다. Claude Code나 Codex 같은 AI 코딩 에이전트와 결합하여 브라우저 기반 작업을 완전한 자유도로 수행할 수 있도록 지원합니다.
