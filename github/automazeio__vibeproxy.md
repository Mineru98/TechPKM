VibeProxy는 기존 Claude Code, ChatGPT, Gemini 등의 AI 구독을 강력한 AI 코딩 툴과 연결해 주는 macOS 네이티브 메뉴 바 앱입니다. 별도의 API 키 없이 OAuth 인증, 토큰 관리, API 라우팅을 자동으로 처리하여 중복 결제를 방지하고 원클릭 인증으로 매끄러운 개발 환경을 제공합니다.
