SQLite3 데이터베이스의 데이터와 스키마를 MySQL 또는 MariaDB로 쉽게 마이그레이션할 수 있는 Python 기반 명령줄 도구입니다. 테이블 필터링, 외래키 처리, 문자셋 설정 등 다양한 옵션을 제공하며, pip, Docker, Homebrew를 통해 편리하게 설치하고 실행할 수 있습니다.
