이 프로젝트는 Google NotebookLM의 내부 API를 활용하여 노트 생성, 소스 관리, 오디오 팟캐스트 생성 등의 기능을 제공하는 Python 기반 CLI 도구입니다. Chrome DevTools Protocol을 사용해 자동 인증을 지원하며, AI 어시스턴트와의 연동을 위한 별도 명령어와 UUID 별칭 시스템을 포함하고 있습니다. 현재 해당 프로젝트는 'NotebookLM MCP CLI'로 통합되면서 더 이상 업데이트되지 않는 상태(Deprecated)입니다.
