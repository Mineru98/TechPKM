Webpack을 기반으로 모듈화되고 최신화된 자바스크립트로 크롬 확장 프로그램을 쉽게 개발할 수 있도록 돕는 보일러플레이트 프로젝트입니다. 팝업, 옵션 페이지, 백그라운드 페이지 구조를 기본 제공하며, 코드 변경 시 브라우저를 자동으로 새로고침하는 핫 리로딩 기능을 지원합니다. 또한 컨텐츠 스크립트 작성, 프로덕션 빌드, API 키 등 보안 정보 관리를 위한 유용한 설정들이 사전에 준비되어 있어 개발 워크플로우를 크게 향상시킵니다.
