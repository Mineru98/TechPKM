JavaScript를 사용하여 HTML 콘텐츠를 Markdown 형식으로 변환해 주는 라이브러리입니다. Node.js와 브라우저 환경 모두에서 사용할 수 있으며, 다양한 변환 옵션과 커스텀 규칙 추가, 플러그인 시스템을 통해 변환 방식을 유연하게 확장할 수 있습니다.
