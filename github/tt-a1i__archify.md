Archify는 Cursor, Claude Code, Codex CLI, OpenCode 같은 AI 에이전트를 위해 설계된 Node.js 기반 다이어그램 렌더링 및 검증 시스템입니다. 에이전트가 생성한 타입화된 JSON IR을 결정적으로 검증하여 아키텍처, 워크플로, 시퀀스, 데이터 흐름, 라이프사이클 다섯 종류의 인터랙티브 HTML/SVG 시스템 맵으로 컴파일합니다. 코드베이스나 시스템 설명만으로 프레젠테이션 가능한 자기완결형 다이어그램을 만들며, 스냅샷 간 Delta 비교, 경로 추적, PNG/SVG/WebM 공유 카드 내보내기 등을 지원합니다.
