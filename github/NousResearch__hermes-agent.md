자체 학습 루프를 탑재하여 경험을 통해 스킬을 생성하고 개선하는 AI 에이전트입니다. 다양한 메시징 플랫폼과 연동되며, 저렴한 VPS부터 서버리스 환경까지 어디서든 실행할 수 있어 특정 디바이스에 종속되지 않는 유연성을 제공합니다. 또한 예약 자동화, 병렬 작업 위임, MCP 통합 등 고급 기능을 지원하여 개인 비서부터 연구 목적까지 폭넓게 활용할 수 있습니다.
