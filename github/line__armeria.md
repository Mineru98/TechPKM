Armeria는 gRPC, Thrift, Spring Boot 등 선호하는 기술을 활용하여 다양한 유형의 마이크로서비스를 구축할 수 있는 리액티브 마이크로서비스 프레임워크입니다. Netty 창시자와 LINE Corporation의 동료들이 개발하였으며, Reactive Streams를 기반으로 유연하고 독립적인 서비스 개발을 지원합니다. Java 8 이상 환경에서 사용할 수 있습니다.
