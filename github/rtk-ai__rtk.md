LLM의 토큰 소비를 60~90%까지 절감해 주는 고성능 CLI 프록시 도구입니다. CLI 에이전트가 실행하는 명령어의 출력물을 스마트 필터링, 그룹화, 절단, 중복 제거 전략을 통해 압축하여 컨텍스트를 최적화합니다. Claude Code, GitHub Copilot, Cursor 등 15개 이상의 AI 코딩 도구와 자동 연동되도록 훅을 제공하며, 10ms 이하의 오버헤드를 자랑하는 단일 Rust 바이너리로 동작합니다.
