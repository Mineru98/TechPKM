생년월일을 입력하면 원국, 십성, 대운, 세운 등 사주 풀이에 필요한 전체 데이터를 한 번에 계산해 주는 초경량 TypeScript 라이브러리입니다. 의존성이 없고 계산 속도가 매우 빠르며, LLM API 호출에 최적화된 압축 텍스트 출력과 UI 표시를 위한 마크다운 출력을 모두 지원합니다.
