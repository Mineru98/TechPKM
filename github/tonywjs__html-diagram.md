html-diagram은 Claude Code(Codex CLI 등 Agent Skills 규격 도구)에서 편집 가능한 HTML 도식·인포그래픽을 생성해 주는 스킬입니다. 산출물은 외부 의존 없는 단일 HTML 파일로, 보기 모드에서는 정적이며 편집 모드(⌘E)에서 노드 드래그, 화살표 편집, 리치 텍스트 편집이 가능하고 같은 파일에 자동 저장됩니다. 최종본은 편집기를 제거한 배포용 정적 HTML로 내보낼 수 있으며, 여러 AI 모델의 생성 품질 비교 결과도 함께 제공합니다.
