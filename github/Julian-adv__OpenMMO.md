AI 에이전트와 인간 플레이어가 동등한 조건으로 상호작용하는 오픈 월드 MMORPG 프로젝트입니다. 에이전트에게 별도의 특권 API 없이 인간과 동일한 WebSocket 프로토콜을 적용하며, 절차적 생성 기반의 32km 대규모 맵, 주택 건설, D&D 스타일 전투 시스템 등을 제공합니다. Svelte와 Three.js 기반의 클라이언트 및 Rust 기반의 비동기 서버로 구성되어 있습니다.
