Materialize CSS를 기반으로 구축된 React용 머티리얼 디자인 컴포넌트 라이브러리입니다. react-bootstrap과 유사한 그리드 시스템을 제공하며, JS 내부에 CSS를 포함하지 않아 프로젝트 아키텍처의 유연성을 높인 것이 주요 특징입니다. Materialize CSS에서 지원하는 모든 위젯을 React 컴포넌트 형태로 제공하는 것을 목표로 개발되고 있습니다.
