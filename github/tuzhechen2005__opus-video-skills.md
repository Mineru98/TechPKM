opus-video-skills는 Claude Code에서 Claude Opus 5.5를 사용해 특정 비주얼 스타일의 완성된 영상을 제작할 수 있게 하는 스킬 모음입니다. 모든 이미지와 음악이 코드로 절차적으로 생성되며, 각 프레임은 시간의 순수 함수로 headless Chrome에서 렌더링되고 ffmpeg로 인코딩됩니다. 수채화 애니메이션 스타일의 painted-animation과 키네틱 타이포그래피 리일 스타일의 kinetic-reel 두 가지 스킬을 제공합니다.
