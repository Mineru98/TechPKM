1MB 모델과 337KB WASM 엔진만으로 브라우저에서 직접 실행되는 초경량 한국어 형태소 분석기입니다. 서버 통신 없이 완전한 오프라인 분석을 지원하며, 코드북 기반의 결정적 알고리즘을 통해 높은 정확도(F1 93.6%)를 제공합니다. Orama나 MiniSearch 같은 JS 검색 라이브러리에 쉽게 통합할 수 있는 어댑터도 제공되어 클라이언트 환경에서의 한국어 텍스트 검색 개선에 유용합니다.
