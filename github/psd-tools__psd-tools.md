Adobe Photoshop PSD 파일의 구조를 읽고 쓰며, 레이어 이미지를 추출하고 기본적인 레이어 합성을 수행할 수 있는 Python 패키지입니다. NumPy 및 PIL 형식의 원본 레이어 이미지 추출을 지원하며, 추가 의존성을 통해 벡터 마스크나 레이어 효과 등의 고급 렌더링 기능도 제공합니다. 포토샵 파일의 하위 데이터 구조를 분석하거나 자동화된 이미지 처리 파이프라인을 구축하는 데 유용합니다.
