텍스트 기반 PDF를 빠르게 분류하고 구조화된 마크다운으로 추출하는 Rust 기반 라이브러리입니다. OCR 없이도 200ms 이내에 로컬 처리가 가능하여, 대규모 PDF 파이프라인에서 불필요한 OCR 비용과 지연 시간을 절감할 수 있도록 설계되었습니다. Python, Node.js, 브라우저 WebAssembly 등 다양한 환경을 위한 바인딩을 제공합니다.
