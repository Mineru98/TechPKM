Apple Silicon Mac 환경에서 카카오톡 로컬 DB를 읽어 키워드, BM25, 시맨틱 벡터 검색을 제공하는 CLI 도구입니다. 대화 내용을 외부 서버로 전송하지 않고 기기 내에 아카이브와 검색 인덱스를 구축하며, Vercel Agent Skills와 연동하여 에이전트 기반 검색도 지원합니다.
