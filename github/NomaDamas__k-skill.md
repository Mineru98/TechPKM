SRT, KTX, 쿠팡, 네이버, 홈택스 등 한국 특화 서비스의 자동화 작업을 AI 코딩 에이전트에게 위임할 수 있도록 모아놓은 스킬 모음집입니다. Claude Code, Codex 등 다양한 에이전트와 호환되며, 별도의 클라이언트 API 레이어 없이 프록시 서버를 통한 HTTP 요청만으로 50개 이상의 기능을 활용할 수 있습니다. 대중교통, 부동산, 스포츠, 쇼핑, 문서 처리 등 일상적이고 반복적인 온라인 작업을 효율적으로 자동화하는 데 목적이 있습니다.
