AI 에이전트의 결정 과정을 추적하고 감사 가능한 형태로 기록하기 위한 그래프 네이티브 인프라 플랫폼입니다. 엔터프라이즈 데이터를 수집하여 컨텍스트 그래프와 지식 그래프를 구축하며, W3C PROV-O 기반의 출처 추적과 결정론적 추론 엔진을 통해 블랙박스 없이 설명 가능하고 규제 요건을 충족하는 AI 시스템 구축을 지원합니다. 다양한 벤더 로직 없이 자체 호스팅이 가능하도록 설계되었습니다.
