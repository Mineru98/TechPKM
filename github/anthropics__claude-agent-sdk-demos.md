이 프로젝트는 Anthropic의 Claude Agent SDK를 활용하여 다양한 AI 애플리케이션을 구축하는 방법을 보여주는 데모 애플리케이션 모음입니다. 이메일 처리, 엑셀 작업, 웹 검색 및 리서치, 이력서 생성 등 실용적인 에이전트 시스템의 구현 예시를 포함하고 있습니다. 각 데모는 로컬 개발 환경에서 SDK의 기능과 세션 관리 패턴을 익히는 것을 목적으로 하며, 프로덕션 배포용이 아닙니다.
