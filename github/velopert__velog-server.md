개발자를 위한 블로그 플랫폼인 Velog의 백엔드 서버 프로젝트입니다. 문법 강조 기능이 지원되는 마크다운 에디터를 제공하는 서비스의 핵심 로직을 담당하며, TypeScript와 Apollo GraphQL 기반으로 구축되었습니다. AWS Lambda 등의 서버리스 아키텍처와 다양한 데이터베이스 기술을 활용하여 확장성 있게 설계되었습니다.
