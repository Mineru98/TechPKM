이 프로젝트는 Claude Code에서 Aseprite를 제어하여 픽셀 아트를 생성, 애니메이션하고 내보낼 수 있는 플러그인입니다. Model Context Protocol(MCP) 서버인 pixel-mcp를 통해 자연어 명령으로 스프라이트를 그리거나 애니메이션을 추가하고, 게임 개발에 필요한 JSON 메타데이터와 함께 PNG, GIF, 스프라이트시트로 내보낼 수 있습니다.
