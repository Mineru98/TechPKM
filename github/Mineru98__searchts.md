TypeScript 객체 및 배열을 쿼리하기 위한 네이티브 JSON 쿼리 포맷이자 참조 구현체입니다. searchjs의 TypeScript 구현으로서, 기본 검색뿐만 아니라 논리 연산, 범위 지정, 정규식, 깊은 탐색 및 속성 검색 등 고급 필터링 기능을 단일 쿼리 객체로 제공합니다. DOM이나 특정 데이터베이스에 종속되지 않고 순수 TypeScript 환경에서 유연하게 데이터를 검색할 수 있도록 설계되었습니다.
