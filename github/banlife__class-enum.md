TypeScript의 기본 enum 기능의 한계를 극복하기 위해, Java의 열거형처럼 생성자와 추가 속성을 지원하는 클래스 기반 열거형 라이브러리입니다. 상속과 메서드 구현을 통해 확장성이 뛰어나며, values, valueOf 등 유용한 API를 제공합니다. Vue.js와 같은 프레임워크 환경에서도 손쉽게 활용할 수 있습니다.
