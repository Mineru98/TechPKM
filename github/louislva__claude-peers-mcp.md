여러 Claude Code 세션 간에 상호 발견 및 메시지 전송을 가능하게 하는 MCP 서버입니다. 로컬 브로커 데몬을 통해 각 인스턴스가 서로를 인식하고, 작업 중인 내용을 공유하며 즉각적으로 통신할 수 있도록 지원합니다. CLI 도구와 자동 요약 기능을 제공하여 다중 에이전트 협업 환경을 손쉽게 구성할 수 있습니다.
