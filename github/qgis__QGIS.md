QGIS는 유닉스, 윈도우, macOS에서 실행되는 완전한 기능을 갖춘 사용자 친화적인 무료 오픈소스 지리 정보 시스템(GIS)입니다. 래스터, 벡터, 메시, 포인트 클라우드 등 다양한 공간 데이터 포맷을 지원하며, 아름다운 지도 제작, 고급 공간 분석, 파이썬 및 C++ 기반의 강력한 확장성을 제공합니다. 또한 동일한 코드베이스를 기반으로 하는 헤드리스 맵 서버(QGIS Server) 기능을 통해 WMS, WFS 등 산업 표준 프로토콜을 지원합니다.
