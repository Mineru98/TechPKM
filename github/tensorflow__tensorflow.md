TensorFlow는 구글 브레인 팀에서 개발한 머신 러닝을 위한 엔드투엔드 오픈소스 플랫폼입니다. 연구자가 최신 ML 기술을 연구하고 개발자가 ML 기반 애플리케이션을 쉽게 구축 및 배포할 수 있도록 포괄적이고 유연한 생태계를 제공합니다. 안정적인 Python 및 C++ API를 기본으로 지원하며, GPU 가속을 통한 고성능 연산 환경을 지원합니다.
