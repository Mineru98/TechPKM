Claude Code, Codex 등 다양한 CLI 기반 AI 에이전트를 하나의 환경에서 병렬로 실행하고 관리할 수 있는 데스크톱 AI 오케스트레이터입니다. 각 에이전트를 독립된 Git 워크트리에 배치하여 결과를 비교하고 병합할 수 있으며, 모바일 앱으로 원격 모니터링도 지원합니다. 고성능 터미널, 내장 브라우저, GitHub 및 Linear 연동 등 개발 워크플로우를 통합한 올인원 도구입니다.
