Context Hub는 코딩 에이전트의 환각 현상을 방지하고 세션 간 학습을 지원하기 위해 설계된 CLI 도구입니다. 에이전트가 웹 검색 대신 큐레이션되고 버전 관리된 문서를 검색하여 가져오도록 유도하며, 주석과 피드백 기능을 통해 에이전트가 작업을 수행할 때마다 점차 더 똑똑해질 수 있도록 돕습니다. 모든 콘텐츠는 Markdown으로 관리되며 오픈 소스 기여가 가능합니다.
