AI Agent 스킬을 검색하고 설치하며 공유할 수 있는 큐레이션 플랫폼 및 크롤러 프로젝트입니다. skills.sh 등의 소스에서 스킬 데이터를 수집하여 JSON, RSS 피드 형식으로 제공하며, 사용자가 웹사이트나 클라이언트에서 쉽게 활용할 수 있도록 데이터를 최신화합니다. GitHub Actions를 통해 매일 자동으로 업데이트되며, 웹 애플리케이션 구축을 위한 데이터 소스로 활용하기에 적합합니다.
