React 환경에서 아름답고 접근성이 뛰어난 리스트 기반의 드래그 앤 드롭 기능을 제공하기 위해 아틀라시안에서 개발한 라이브러리입니다. 키보드 및 스크린 리더 지원, 가상 리스트, 멀티 드래그 등 다양한 기능을 갖추고 있었으나, 현재는 프로젝트가 아카이브되어 새로운 Pragmatic drag and drop으로 대체되었습니다.
