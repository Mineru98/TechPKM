GitHub 리포지토리에 YouTube 동영상을 임베드할 때, 단순한 썸네일 이미지 대신 재생 버튼 등 시각적 단서를 추가해 동영상임을 명확하게 인식할 수 있도록 돕는 도구입니다. 기존에 수동으로 썸네일 스크린샷을 활용하던 방식을 자동화하여 Markdown 환경에서 더욱 직관적인 YouTube 임베드 효과를 제공합니다. Nix 셸 환경에서 Gunicorn을 통해 웹 서버로 실행 및 배포할 수 있습니다.
