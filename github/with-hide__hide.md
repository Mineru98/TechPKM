hide는 여러 코딩 AI 에이전트(Claude Code, Codex 등)를 하나의 화면에서 실행하고 관리하는 데스크톱 ADE(Agent Development Environment)입니다. 에이전트 세션을 읽어 사용자의 개입이 필요한 작업만 알려주고, 에이전트 간 통신·감독, 프로젝트 메모리 공유, 브라우저 자동화, PR 관리 등을 지원합니다. Rust 코어와 Electron 기반으로 macOS, Windows, Linux에서 동작하며, 호스팅 없이 사용자 자신의 머신과 로그인 상태에서 완전히 실행됩니다.
