herdr web ui는 AI 에이전트 실행 도구인 herdr(0.9.0+)를 위한 브라우저 및 모바일 클라이언트로, 실행 중인 에이전트 세션을 대화형 채팅과 터미널 형태로 확인하고 어디서든 응답할 수 있게 해줍니다. Claude Code, Codex 등 다양한 에이전트의 승인·질문을 카드 형태로 처리하고, 파일 뷰어와 SSH 원격 PC 연동을 지원하며, PWA로 스마트폰에 설치해 푸시 알림과 모바일 키보드 보조 키를 활용할 수 있습니다. MIT 라이선스로 배포되며 Bun, React, xterm.js 기반으로 개발되었습니다.
