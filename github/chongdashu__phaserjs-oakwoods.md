Phaser 3와 TypeScript, Vite를 사용하여 구축된 2D 플랫포머 게임 프로젝트입니다. 'Vibe Coding' 튜토리얼의 예제 코드로, 패럴랙스 배경과 무한 지형, 캐릭터 움직임 및 공격 시스템을 구현하는 방법을 보여줍니다. 또한 Claude Code 및 Codex CLI 사용을 위한 Agent Skill 파일과 Playwright 테스팅 스킬을 포함하고 있어 AI 기반 게임 개발 워크플로우를 학습하는 데 활용할 수 있습니다.
