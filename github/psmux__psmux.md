WSL, Cygwin 등의 에뮬레이션 없이 Windows 환경에서 동작하는 네이티브 터미널 멀티플렉서입니다. Rust로 작성되었으며 tmux 명령어 언어와 설정 파일을 그대로 지원하고, 마우스 인터랙션 및 테마 호환성을 제공합니다. Claude Code 에이전트 팀과의 연동 등 최신 개발 워크플로우를 Windows 터미널 환경에서 원활하게 사용할 수 있도록 지원합니다.
