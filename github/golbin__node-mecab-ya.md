Node.js 환경에서 MeCab 형태소 분석기를 쉽게 사용할 수 있도록 제작된 래퍼 라이브러리입니다. 일본어 및 한국어 텍스트의 품사 태깅, 형태소 추출, 명사 추출 기능을 비동기 및 동기 방식으로 모두 지원합니다. 외부 MeCab 라이브러리 경로를 자유롭게 설정할 수 있어 AWS Lambda 등의 환경에 내장형으로 배포하는 데 유리합니다.
