macOS 환경에서 앱 종료를 방지하고 개별 앱에 독립적인 단축키 매핑을 지원하는 유틸리티 애플리케이션입니다. Command+Q를 두 번 눌러야 앱이 종료되도록 설정하여 실수로 앱이 닫히는 것을 예방하며, 마우스 휠 방향 변경 등 세부적인 입력 설정도 제공합니다.
