다양한 뷰포트 크기에서 제목의 줄바꿈을 최적화하여 가독성을 높여주는 React 컴포넌트입니다. 마지막 줄에 단어 하나만 남는 등 불균형한 텍스트 배치를 자동으로 교정하며, 네이티브 CSS 텍스트 균형 기능을 지원합니다. Provider를 통해 여러 컴포넌트의 재균형화 로직을 공유하여 성능과 HTML 크기를 최적화할 수 있습니다.
