ScrollMagic 라이브러리를 React에서 선언적인 방식으로 사용할 수 있도록 제공하는 컴포넌트 라이브러리입니다. Controller와 Scene 컴포넌트를 통해 스크롤 기반 애니메이션과 고정(Pin) 효과 등을 쉽게 구현할 수 있습니다. 현재는 개발이 중단된 상태이며, 작성자는 후속 대안으로 GSAP ScrollTrigger를 포함한 react-gsap 라이브러리의 사용을 권장하고 있습니다.
