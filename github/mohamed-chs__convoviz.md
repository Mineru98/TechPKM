ChatGPT 대화 기록을 Markdown 파일로 변환하여 보관하거나 Obsidian 같은 메모 앱과 연동할 수 있게 해주는 Python 도구입니다. 워드 클라우드와 사용량 그래프를 통해 데이터를 시각화할 수 있으며, 대화 내용뿐만 아니라 인라인 이미지와 인용 링크, 커스텀 지침 등을 깔끔하게 추출하는 것이 주요 특징입니다.
