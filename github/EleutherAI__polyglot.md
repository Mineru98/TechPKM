기존 다국어 모델들이 비영어권 언어에 대해 보여주는 성능 한계를 극복하고자 개발된 균형 잡힌 다국어 대규모 언어 모델 프로젝트입니다. 핵심 산출물인 Polyglot-Ko는 1.2TB 규모의 한국어 데이터로 학습된 오픈소스 한국어 특화 모델로, 다양한 크기(1.3B~12.8B)로 제공됩니다. 또한 StabilityAI Japan과의 협업을 통해 일본어 언어 모델인 Japanese StableLM 개발에도 기여하며, 다국어 자연어 처리 생태계 확장에 기여하고 있습니다.
