React 애플리케이션에 사용자 가이드 투어를 쉽게 구현할 수 있도록 도와주는 라이브러리입니다. 컴포넌트와 훅 API를 제공하여 스타일 및 컴포넌트 커스터마이징이 가능하며, 접근성과 SSR 환경을 완벽하게 지원합니다. 신규 사용자 온보딩이나 새로운 기능 설명에 최적화된 가벼운 번들 사이즈가 특징입니다.
