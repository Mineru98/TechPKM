Claude Cowork와 Claude Code를 위한 커뮤니티 기여 플러그인 마켓플레이스의 읽기 전용 미러 저장소입니다. 모든 플러그인은 제출 후 자동 보안 검사를 통과하고 승인된 것으로, `marketplace.json` 목록이 매일 밤 Anthropic의 내부 검토 파이프라인에서 동기화됩니다. 플러그인 설치는 claude.com/plugins 또는 `claude plugin` CLI 명령어를 통해 가능하며, 제출은 전용 페이지를 통해서만 허용됩니다.
