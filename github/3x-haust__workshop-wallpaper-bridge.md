로컬에 복사된 Wallpaper Engine 워크숍 파일을 macOS 데스크톱 배경화면으로 재생할 수 있도록 지원하는 macOS 전용 유틸리티입니다. 메뉴 막대에서 실행되며, 비디오, 웹, 이미지 및 기본 씬 파일을 가져와 재생하고 화면 보호기 기능도 제공합니다. Steam이나 외부 네트워크와 통신하지 않고 온전히 로컬 환경에서만 동작하도록 설계되었습니다.
