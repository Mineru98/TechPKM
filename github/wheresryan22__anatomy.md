Anatomy는 Claude Code(및 Antigravity, OpenCode, Codex, MiniMax Code)에서 동작하는 스킬로, 기술 개념을 설명하기 위해 그 개념의 작동 방식을 그대로 담은 실제 물건을 발명하고, 이를 수십 개의 정밀한 부품으로 구성된 인터랙티브 아이소메트릭 도해로 만들어 줍니다. SVG, SVG+WebGL, 3D(베타) 세 종류의 도해를 생성하며, 외부 의존성 없이 Node.js 빌드 스크립트, 단일 SVG 파일 또는 React/Next.js 컴포넌트 형태로 결과물을 제공합니다. 지오메트리 감사(audit)와 헤드리스 Chrome 기반 스크린샷 검증으로 스스로 결과물의 품질을 점검하는 것이 특징입니다.
