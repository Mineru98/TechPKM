KSS(Korean String processing Suite)는 자연어 처리, 데이터 전처리, 분석 등 다양한 분야에서 사용할 수 있는 한국어 문자열 처리 도구 모음입니다. 문장 분리, 형태소 분석, 한글 변환, 텍스트 정규화, 개인정비 익명화 등 40개 이상의 기능을 제공하며, 간단한 사용법과 병렬 처리 기능을 특징으로 합니다. Python을 비롯해 Java, Flutter, C++ 등 다양한 언어로 포팅되어 있습니다.
