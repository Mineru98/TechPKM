anydoc는 Word, PowerPoint, Excel, OpenDocument, RTF, EPUB, CSV, PDF 등 다양한 오피스 문서를 빠르고 일관된 GitHub-Flavored Markdown으로 변환하는 순수 Rust 라이브러리입니다. Node.js, Python, WebAssembly(브라우저) 바인딩과 CLI를 제공하며, LLM 친화적인 Markdown 출력을 밀리초 단위로 생성합니다. 스캔된 PDF는 Firecrawl Parse 호스티드 OCR을 옵트인 방식으로 사용할 수 있습니다.
