React 애플리케이션에서 손쉽게 A/B 테스트를 구현할 수 있도록 돕는 컴포넌트 및 훅 라이브러리입니다. Experiment와 Variant 컴포넌트를 통해 사용자에게 무작위로 다른 UI를 제공하며, 로컬 스토리지를 통해 일관된 경험을 유지합니다. Mixpanel이나 Segment 같은 분석 도구와의 연동, 가중치 적용, 서버 사이드 렌더링 지원 등 실무 환경에 필요한 다양한 기능을 제공합니다.
