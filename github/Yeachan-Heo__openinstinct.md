OpenInstinct는 Mac에서 상시 실행되는 개인 AI 에이전트(캐릭터명 "Gajae")로, 채팅 창을 통해 사용자와 대화하며 선택적으로 iMessage를 연결해 휴대폰 문자로도 소통할 수 있습니다. 자체 Chrome 프로필로 웹 브라우징, git 기반 장기 기억, 백그라운드 작업, cron/파일/웹훅 모니터링 등을 수행하며, 모든 데이터는 모델 호출 외에는 로컬에 머무릅니다. 메뉴 바 SwiftUI 패널과 단일 명령 설치 스크립트를 통해 손쉽게 설정하고 관리할 수 있습니다.
