Node Version Manager(nvm)는 POSIX 호환 셸(sh, bash, zsh 등)을 사용하여 단일 사용자 환경에서 Node.js 버전을 설치, 관리 및 전환할 수 있도록 설계된 도구입니다. 개발자는 이 도구를 사용하여 프로젝트별로 서로 다른 Node.js 버전을 신속하게 설치하고, `.nvmrc` 파일을 통해 자동으로 버전을 전환하며 기존 버전에서 설치된 전역 패키지를 새 버전으로 마이그레이션할 수 있습니다. macOS, Linux, Windows WSL 환경을 지원하며, 독립 실행형 바이너리가 아닌 셸 함수로 작동하여 프로젝트 개발 환경을 유연하게 제어합니다.
