TypeScript를 기반으로 React Native 프로젝트를 빠르게 시작할 수 있도록 돕는 깔끔하고 미니멀한 템플릿입니다. 기본 React Native 템플릿과의 일관성을 유지하며 불필요한 의존성을 최소화한 것이 특징입니다. 단, React Native 0.71 버전부터 TypeScript가 기본 지원됨에 따라 현재 이 템플릿은 더 이상 업데이트되지 않는 deprecated 상태입니다.
