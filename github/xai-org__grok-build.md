SpaceXAI에서 개발한 터미널 기반 AI 코딩 에이전트인 Grok Build입니다. 전체 화면 TUI 환경에서 코드베이스를 이해하고 파일을 편집하며, 쉘 명령 실행 및 웹 검색 등의 작업을 수행할 수 있습니다. 대화형 모드뿐만 아니라 스크립팅 및 CI용 헤드리스 모드, 에디터 임베디드 모드(ACP)를 모두 지원합니다.
