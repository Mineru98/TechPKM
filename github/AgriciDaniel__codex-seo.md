OpenAI의 Codex 환경에 최적화된 전문 SEO(검색엔진최적화) 분석 및 감사 스킬 스위트입니다. 기술적 SEO, 콘텐츠 품질, 스키마 마크업, 로컬 SEO 등 총 26개의 세부 전문 워크플로우와 24개의 TOML 에이전트를 통해 포괄적인 사이트 진단을 수행합니다.

사용자의 자연어 요청을 오케스트레이터가 파악하여 적절한 전문가 에이전트로 라우팅하며, DataForSEO, Google APIs, Firecrawl 등의 외부 확장 기능을 연동하여 실시간 데이터 기반의 심층적인 분석을 제공합니다. 결괏값으로 체계적인 마크다운, JSON, HTML/PDF 형태의 프리미엄 감사 보고서를 생성하여 웹사이트의 검색 성능과 가시성을 개선하는 데 목적이 있습니다.
