Ant Motion은 Ant Design의 모션 디자인 명세를 제공하는 솔루션으로, React 애플리케이션에 즉시 사용 가능한 다양한 애니메이션 컴포넌트를 제공합니다. 간단한 설정만으로 요소의 스타일 변화, 순차적 렌더링, 스크롤 연동 및 배너 슬라이더 등을 구현할 수 있어 랜딩 페이지 제작에 매우 유용합니다. UX의 편안함과 UI의 생동감을 높이는 데 초점을 맞추어 설계되었습니다.
