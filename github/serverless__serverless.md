Serverless Framework는 AWS Lambda를 비롯한 관리형 클라우드 서비스를 쉽게 사용할 수 있도록 돕는 명령줄 도구입니다. 직관적인 YAML 구문을 통해 코드와 인프라를 함께 배포할 수 있으며, 다양한 프로그래밍 언어를 지원하고 풍부한 플러그인 생태계를 제공합니다. 최신 V.4 버전에서는 하이브리드 로컬 개발 모드, 내장 TypeScript 지원, 컨테이너 배포 기능 등이 추가되어 서버리스 애플리케이션의 개발 및 운영 경험을 크게 향상시켰습니다.
