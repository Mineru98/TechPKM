OpenClaw을 AWS 서버리스 인프라(AWS CDK, ECS Fargate) 위에서 온디맨드로 실행하여 비용을 최적화한 오픈소스 프로젝트입니다. 웹 채팅 UI와 텔레그램 봇을 인터페이스로 제공하며, 예약된 사전 워밍을 통해 콜드 스타트를 없애고 Fargate Spot을 사용해 월 $1 수준의 저렴한 비용으로 LLM 기반 자동화 작업을 수행할 수 있습니다.
