datapitfalls는 데이터 작업 전 과정(질문 정의부터 시각화, 해석, 커뮤니케이션까지)에서 발생하는 흔한 실수를 탐지하는 오픈소스 도구입니다. Ben Jones의 책 『Avoiding Data Pitfalls』의 8개 함정 도메인 분류 체계를 기반으로, Claude API를 활용해 차트 이미지, 코드 스니펫, 일반 텍스트 설명, PDF 보고서 등을 스캔하고 구조화된 감사 보고서를 반환합니다. CLI, 웹 앱, 그리고 Claude용 MCP 서버 형태로 사용할 수 있으며, 라이브러리로서 프로그래밍 방식 API도 제공합니다.
