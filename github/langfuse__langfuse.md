Langfuse는 팀이 AI 애플리케이션을 협업하여 개발, 모니터링, 평가 및 디버깅할 수 있도록 지원하는 오픈 소스 LLM 엔지니어링 플랫폼입니다. 클라우드와 자체 호스팅 환경 모두를 지원하며, LLM 호출 추적, 프롬프트 버전 관리, 모델 평가, 데이터셋 관리 등 LLM 애플리케이션 수명 주기 전반을 관리하는 핵심 기능을 제공합니다. 다양한 LLM 프레임워크 및 모델 제공업체와의 원활한 통합을 통해 복잡한 로그와 사용자 세션을 쉽게 검사하고 디버그할 수 있습니다.
