iTerm2의 Python API를 활용하여 터미널 세션, 창, 탭, 프로필 관리 및 입력 브로드캐스팅 등을 제어할 수 있는 강력한 CLI 도구입니다. YAML 기반의 설정을 지원하여 복잡한 개발 환경을 자동화하고 구성할 수 있으며, 터미널 운영 효율성을 크게 높여줍니다.
