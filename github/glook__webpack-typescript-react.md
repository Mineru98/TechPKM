React, TypeScript, Sass/Less 및 다양한 최신 프론트엔드 개발 도구가 통합된 Webpack 5 보일러플레이트입니다. Babel, ESLint, Prettier, CSS Modules, React Refresh 등 실무에서 자주 사용되는 로더와 플러그인이 기본적으로 설정되어 있어 프로젝트 초기 구축 시간을 크게 단축할 수 있습니다.
