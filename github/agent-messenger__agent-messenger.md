Agent Messenger는 Slack, Discord, Teams, KakaoTalk 등 12개 이상의 메신저 플랫폼을 하나의 CLI와 TypeScript SDK로 사용할 수 있게 해주는 도구입니다. OAuth나 봇 토큰 없이 데스크톱 앱 또는 브라우저에서 세션 자격 증명을 추출하거나 QR 코드 로그인을 통해, AI 에이전트가 사용자 본인의 신원으로 메시지를 주고받을 수 있습니다. JSON 기반의 에이전트 친화적 출력과 Agent Skills를 제공하여 컨텍스트 수집, 보고, 자동화 파이프라인 등 다양한 워크플로우에 활용할 수 있습니다.
