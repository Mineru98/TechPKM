이 프로젝트는 모델 컨텍스트 프로토콜(MCP)을 위한 참조 구현(reference implementations)을 포함하고 있으며, 다양한 공식 및 커뮤니티 주도의 MCP 서버와 리소스를 중앙에서 관리하고 제공합니다. LLM(대규모 언어 모델)이 도구 및 데이터 소스에 안전하게 접근할 수 있도록 돕는 TypeScript 및 Python 기반 서버들을 포함하며, 개발자가 자체 MCP 서버를 구축하기 위한 교육적 예시로 활용됩니다.
