사용자 개인의 클로드(Claude) 어시스턴트를 안전한 컨테이너 환경에서 실행하기 위해 설계된 경량형 프로젝트입니다. 복잡한 추상화 계층을 제거하여 단일 프로세스와 핵심 파일만으로 구성되며, 에이전트는 리눅스 컨테이너(Docker 또는 Apple Container) 내에서 격리되어 실행됩니다. WhatsApp 연동, 예약 작업 스케줄링, 에이전트 스움(Agent Swarms) 기능을 제공하며, 설정이나 기능 추가는 Claude Code를 통해 직관적으로 수행하도록 설계되었습니다.
