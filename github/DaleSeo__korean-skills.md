Claude Code, Cursor 등 Agent Skills 형식을 지원하는 AI 에이전트를 위한 한국어 특화 스킬 모음입니다. AI 생성 텍스트를 자연스럽게 교정하는 humanizer, 문법·맞춤법 검사 grammar-checker, 문서 일관성 점검 style-guide의 세 가지 스킬을 제공하며, 슬래시 명령어나 npx, GitHub CLI 등으로 간편히 설치할 수 있습니다. 세 스킬을 순차적으로 적용하는 3-스킬 파이프라인으로 한국어 글쓰기를 종합적으로 검토할 수 있습니다.
