Dalai는 사용자의 개인 컴퓨터에서 LLaMA 및 Alpaca와 같은 대규모 언어 모델(LLM)을 손쉽게 실행할 수 있도록 돕는 프로젝트입니다. llama.cpp를 기반으로 구동되며, 모델 다운로드부터 웹 UI 제공, JavaScript 및 Socket.io 기반의 API 연동 기능까지一站式로 제공합니다. Windows, Mac, Linux 등 다양한 운영체제를 지원하여 복잡한 설정 없이도 로컬 환경에서 LLM을 실험하고 활용할 수 있습니다.
