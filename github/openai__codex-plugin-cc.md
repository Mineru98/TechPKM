Claude Code 내부에서 OpenAI Codex를 연동하여 코드 리뷰 및 작업 위임을 수행할 수 있는 플러그인입니다. 읽기 전용 리뷰, 대립적 설계 검토, 백그라운드 작업 관리 등의 슬래시 명령어를 제공하여 기존 Claude Code 워크플로우에 Codex를 원활하게 통합합니다.
