Claude Code 등 코딩 에이전트가 생성하는 기계번역투의 저품질 한국어 출력을 개선하기 위한 출력 스타일(Output Style) 플러그인입니다. 생략된 조사와 어미, 원어민이 사용하지 않는 비유적 어휘 등을 바로잡아 의미 손실 없이 명확하고 자연스러운 한국어를 구사하도록 사전에 규율합니다. Claude Code CLI 환경에 최적화되어 있으나, 지침 텍스트를 활용하면 다른 AI 환경에도 범용적으로 적용할 수 있습니다.
