ONLYOFFICE Docs(Document Server)를 Docker 컨테이너로 손쉽게 배포하고 구성할 수 있도록 지원하는 프로젝트입니다. 문서, 스프레드시트, 프레젠테이션, PDF 등 다양한 형식의 파일을 실시간 협업으로 편집할 수 있는 오픈소스 오피스 제품군을 제공합니다. Nextcloud, Moodle 등 서드파티 솔루션과의 연동을 지원하며, HTTPS, 데이터 볼륨 마운트, Docker Compose를 통한 설치 등 운영 환경에 맞는 세부 설정이 가능합니다.
