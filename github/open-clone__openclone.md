Claude Code 환경에서 슬래시 커맨드 하나로 AI 페르소나 클론을 생성, 활성화 및 관리할 수 있는 로컬 기반 스킬입니다. 다양한 실존 인물의 관점을 재현하는 프리셋 클론을 제공하며, 단체 대화방과 카테고리 패널을 통해 여러 관점을 동시에 비교할 수 있습니다. 모든 데이터는 외부 서버 없이 사용자 컴퓨터에 마크다운 형태로 저장됩니다.
