안드레이 카르파시의 LLM 코딩 문제점 분석에서 파생된 Claude Code 동작 개선 가이드라인 프로젝트입니다. 코드를 작성하기 전에 명확히 생각하고, 단순함을 우선시하며, 필요한 부분만 정확히 수정하고, 목표 기준을 설정해 검증하는 4가지 핵심 원칙을 제공합니다. 이 가이드라인은 CLAUDE.md 파일이나 Claude Code 플러그인으로 적용하여 AI 코딩 에이전트의 불필요한 과공학과 사이드 이펙트를 방지하는 데 목적이 있습니다.
