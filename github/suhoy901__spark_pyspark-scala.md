이 프로젝트는 Apache Spark의 핵심 개념인 RDD, DataFrame, 그리고 MLlib를 다루는 포괄적인 튜토리얼과 실전 예제를 포함하고 있습니다. Python(PySpark)과 Scala를 사용하여 데이터 전처리, 추천 시스템 구현, 분류 모델링 및 스트리밍 처리 등을 다루며, 머신러닝 파이프라인 구축 방법을 설명합니다. 특히 MovieLens 데이터셋을 활용한 추천 시스템과 Kaggle 데이터를 활용한 분류 모델 프로젝트를 포함하여 실무 적용 능력을 높이는 데 중점을 두고 있습니다.
