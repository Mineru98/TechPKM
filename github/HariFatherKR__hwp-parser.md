LLM 및 RAG 파이프라인 활용을 최적화하기 위해 설계된 한글(HWP) 문서 파서 및 변환기입니다. 바이너리 HWP 파일에서 텍스트를 추출하여 HTML, ODT, PDF 등으로 변환할 수 있으며, Markdown이나 HTML을 HWPX 포맷으로 생성하는 기능을 제공합니다. CLI 도구와 Python API를 통해 LangChain 연동 및 배치 처리가 지원되어 대규모 문서 처리 작업에 효율적입니다.
