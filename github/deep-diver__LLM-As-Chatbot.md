다양한 오픈소스 명령어 수행형 LLM 모델을 챗봇 서비스로 쉽게 배포하고 사용할 수 있도록 지원하는 프로젝트입니다. 모델별로 상이한 프롬프트 형식을 추상화하여 처리하며, Gradio 웹 UI와 Discord 봇 형태로 서비스할 수 있는 기능을 제공합니다. 또한 Serper API를 연동한 인터넷 검색 기능과 효율적인 대화 컨텍스트 관리 기능을 포함하고 있습니다.
