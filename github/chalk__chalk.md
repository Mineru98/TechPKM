터미널 및 콘솔 환경에서 문자열의 스타일(색상, 굵기, 밑줄 등)을 적용하기 위해 사용하는 Node.js 라이브러리입니다. 메소드 체이닝 방식을 지원하여 직관적이고 간편하게 스타일을 조합할 수 있으며, 자동으로 색상 지원 여부를 감지합니다. 의존성이 없고 성능이 우수하여 CLI 도구 개발 시 로그를 시각적으로 구성하는 데 널리 사용됩니다.
