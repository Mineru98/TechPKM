Ultralytics에서 개발한 최신 YOLO 모델을 포함하는 컴퓨터 비전 프레임워크입니다. 객체 탐지, 인스턴스 분할, 이미지 분류, 자세 추정 등 다양한 작업을 지원하며, CLI와 Python API를 통해 간편하게 사용할 수 있습니다. 빠르고 정확하며 유연한 성능을 제공하여 연구 및 상용 환경 모두에 적합합니다.
