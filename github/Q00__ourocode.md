Ourocode는 터미널 환경을 벗어나지 않고 구조화된 AI 에이전트 워크플로우를 실행할 수 있도록 설계된 터미널 네이티브 AI 워크벤치입니다. MCP 및 Ouroboros 워크플로우 오케스트레이션, wonderTool 결정 체크포인트, 로컬 명령어 탐색 기능을 통합적으로 제공하며, Claude CLI, Codex CLI, Gemini CLI 등 다양한 모델 백엔드를 지원합니다. Elixir 기반의 escript와 Rust 기반의 tty 헬퍼로 구축되어 가볍고 빠른 터미널 인터페이스를 제공하며, 현재 macOS 환경에서의 로컬 개발 및 초기 사용자 테스트에 최적화되어 있습니다.
