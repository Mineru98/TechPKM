Google Antigravity AI 모델의 사용량과 남은 할당량을 실시간으로 모니터링해 주는 VS Code 확장 프로그램입니다. 웹뷰 대시보드와 QuickPick 모드를 지원하며, 상태 표시줄 연동, 임계값 알림, 모델 그룹화, 드래그 앤 드롭 정렬 등의 기능을 제공합니다. 또한 지정된 시간에 AI 모델을 자동으로 호출하여 할당량 초기화 주기를 앞당기는 예약 실행 기능을 포함하고 있습니다.
