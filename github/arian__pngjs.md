Node.js와 현대 브라우저 환경 모두에서 동작하는 순수 JavaScript 기반의 PNG 디코더입니다. Buffer, 바이트 문자열, ArrayBuffer 등 다양한 입력 형식을 지원하며, 이미지 메타데이터뿐만 아니라 픽셀 데이터에도 쉽게 접근할 수 있는 API를 제공합니다. Browserify를 통해 브라우저용으로 빌드하여 사용할 수 있습니다.
