Atropos 환경과 Thinking Machines의 Tinker API를 연결하는 통합 레이어입니다. 로컬 머신에서 인프라 관리나 컴퓨팅 리소스 걱정 없이 Atropos 기반의 모델 학습을 원활하게 수행할 수 있도록 추상화를 제공합니다. 기존 Atropos 환경을 추가 수정 없이 Tinker 학습 파이프라인과 함께 사용할 수 있는 것이 핵심 특징입니다.
