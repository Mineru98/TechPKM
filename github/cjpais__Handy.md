Tauri(Rust + React) 기반의 오픈 소스 크로스 플랫폼 데스크톱 응용 프로그램으로, 클라우드 연결 없이 완전히 오프라인에서 작동하는 프라이버시 중심의 음성 인식 기능을 제공합니다. 사용자는 단축키를 눌러 말하기만 하면 Whisper 또는 Parakeet 모델을 통해 텍스트가 변환되어 현재 사용 중인 앱에 자동으로 입력됩니다. 확장 가능하고 수정이 용이한 구조를 제공하여 다양한 하드웨어 환경에서 로컬 데이터 보안을 유지하며 손쉽게 음성을 텍스트로 변환할 수 있도록 설계되었습니다.
