macOS용 고화질 화면 캡처, AI 분석 및 GUI 자동화를 제공하는 도구입니다. CLI 및 MCP 서버를 통해 자연어 기반 에이전트 흐름과 멀티 스크린 자동화를 지원하며, OpenAI, Claude, Ollama 등 다양한 AI 제공자와 연동됩니다. 주요 기능으로는 UI 요소 자동 식별, 클릭/입력/스크롤 제어, 메뉴 탐색 등이 포함됩니다.
