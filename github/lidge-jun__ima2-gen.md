ChatGPT 및 Grok OAuth를 활용하여 로컬 환경에서 이미지와 비디오를 생성할 수 있는 데스크톱 형태의 웹 애플리케이션입니다. 다양한 생성 모드(클래식, 노드, 멀티모드, 캔버스)와 프롬프트 라이브러리, 로컬 갤러리 기능을 제공하며, CLI와 Docker를 통해 손쉽게 설치하고 실행할 수 있습니다. API 키 없이도 기본 OAuth 경로로 바로 사용할 수 있어 접근성이 뛰어난 로컬 AI 이미지 생성 스튜디오입니다.
