Warp는 터미널을 기반으로 구축된 에이전트형 개발 환경으로, 내장된 코딩 에이전트를 제공하며 Claude Code, Codex 등 외부 CLI 에이전트도 함께 사용할 수 있습니다. 클라이언트 코드베이스가 오픈소스로 공개되어 있으며, AGPL v3 및 MIT 라이선스를 적용하여 커뮤니티 기여를 적극적으로 지원합니다.
