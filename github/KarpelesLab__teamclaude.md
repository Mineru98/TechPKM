Claude Code와 Anthropic API 사이에 위치하여 여러 Claude 계정을 관리하고, 세션 및 주간 할당량에 도달하면 자동으로 계정을 전환하는 다중 계정 프록시 도구입니다. MITM 프록시, 할당량 추적, 429 에러 자동 재시도, 스트orm 컨트롤 등 고도화된 트래픽 관리 기능을 제공하며, Node.js 내장 모듈만으로 구현되어 외부 의존성이 없습니다.
