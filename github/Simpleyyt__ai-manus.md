AI Manus는 Docker 샌드박스 환경에서 다양한 도구와 작업을 실행할 수 있는 범용 AI 에이전트 시스템입니다. 터미널, 브라우저, 파일 검색 등의 기능을 안전하게 관리하며, MongoDB/Redis를 통해 세션 기록을 처리하고 백그라운드 작업을 지원합니다. 사용자는 Docker Compose를 통해 쉽게 배포하고 LLM 서비스만으로 자신만의 에이전트를 구축할 수 있습니다.
