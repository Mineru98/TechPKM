이 프로젝트는 Claude Code Sub-Agent와 스킬(Skill) 기반 아키텍처를 활용하여 프레젠테이션 생성 과정을 자동화하는 도구입니다. HTML 콘텐츠를 PPTX 파일로 변환하는 기능을 핵심으로 하며, pptxgenjs와 Playwright 등의 기술을 사용하여 AI 기반의 콘텐츠 생성 및 이미지 처리를 지원합니다.
