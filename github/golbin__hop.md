HOP는 macOS, Windows, Linux 환경에서 HWP/HWPX 문서를 보고 편집할 수 있는 오픈소스 데스크탑 애플리케이션입니다. 문서 파싱 및 렌더링 엔진인 rhwp를 기반으로 구축되었으며, 파일 열기, 저장, PDF 내보내기, 인쇄 및 OS 파일 연결 기능을 제공합니다.
