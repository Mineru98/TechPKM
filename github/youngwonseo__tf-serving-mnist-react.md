TensorFlow Serving를 활용한 간단한 손글씨 숫자 인식(MNIST) 예제 프로젝트입니다. React와 Redux 기반의 프론트엔드에서 입력을 받아 Docker와 Nginx로 구성된 환경을 통해 MLP 모델로 추론을 수행합니다. 전체 시스템은 Docker Compose를 통해 쉽게 실행하고 테스트할 수 있도록 구성되어 있습니다.
