macOS 환경에서 카카오톡을 명령줄 인터페이스(CLI)로 제어할 수 있게 해주는 도구입니다. 로컬의 암호화된 데이터베이스를 읽어 채팅 내역을 조회하고 검색할 수 있으며, macOS 접근성 API를 활용해 메시지 전송 등의 UI 자동화를 수행합니다. 특히 카카오 공식 API에서 지원하지 않는 채팅 기록 읽기와 자유로운 메시지 전송 기능을 CLI 환경에서 제공하여 사용성을 크게 높입니다. 모든 명령어가 JSON 형식의 출력과 웹훅을 지원하도록 설계되어 Claude Code 등 다양한 AI 에이전트와의 실시간 연동 및 작업 자동화에 최적화되어 있습니다.
