이 프로젝트는 웹페이지 내에서 자연어 명령을 통해 UI를 제어할 수 있는 클라이언트 사이드 AI 에이전트인 'Page Agent'입니다. 별도의 브라우저 확장 프로그램이나 백엔드 수정 없이 JavaScript만으로 SaaS 앱의 AI 코파일럿을 구축하거나, 복잡한 양식 작업 및 접근성 기능을 자동화하는 데 사용됩니다. 사용자가 직접 LLM을 연결하여 DOM 기반의 텍스트 명령을 처리하고 인간 개입이 가능한 UI를 제공하는 것이 주요 특징입니다.
