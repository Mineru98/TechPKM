Claude Code를 위한 웹 접근성 극대화 플러그인으로, WAF, CAPTCHA, 로그인 벽 등으로 접근이 차단된 웹사이트를 5단계 적응형 탐색 단계를 통해 자동으로 우회하고 콘텐츠를 추출합니다. 별도의 API 키나 설정 없이 설치만으로 작동하며, TLS 위장 및 숨겨진 API 발견 등의 기술을 활용하여 사전에 차단되지 않는 어떤 사이트든 접근을 시도합니다. 키워드 의도 파악을 통한 검색 라우팅과 주요 플랫폼 및 한국 사이트 특화 엔드포인트 인덱스를 제공합니다.
