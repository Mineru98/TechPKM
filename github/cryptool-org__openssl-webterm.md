OpenSSL Webterm은 OpenSSL v3를 Emscripten으로 WebAssembly로 컴파일하여 브라우저의 터미널 에뮬레이터(xterm.js)에서 실행할 수 있게 한 웹 앱입니다. CrypTool 프로젝트가 2021년에 교육 목적으로 개발했으며, 초보자도 쉽게 사용할 수 있도록 GUI를 제공하고 GUI 작업을 실제 OpenSSL 명령어로 변환해 문법을 자연스럽게 학습할 수 있게 합니다. Node.js 환경에서 실행하거나 Docker로 직접 호스팅할 수 있습니다.
