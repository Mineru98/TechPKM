자바스크립트의 Lodash 라이브러리처럼 유용한 Kotlin 확장 함수들을 모아놓은 라이브러리입니다. 누구나 포크하여 새로운 확장 함수를 추가하고 풀 리퀘스트를 통해 기여할 수 있는 오픈소스 프로젝트입니다. 코틀린 개발 시 반복적으로 작성하는 유틸리티 코드의 간소화를 목적으로 합니다.
