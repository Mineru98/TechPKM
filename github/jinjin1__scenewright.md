소스 텍스트를 한국어 내레이션과 Remotion 렌더링이 적용된 YouTube explainer 영상으로 변환해 주는 Claude Code 네이티브 파이프라인입니다. 각 단계를 JSON 계약으로 연결하여 언제든 중단하고 검수할 수 있는 구조적 제작 방식을 채택했으며, 로컬 Supertonic TTS와 무료 스톡 미디어를 활용해 영상당 비용을 ~$0로 절감합니다. 주제나 도메인에 구애받지 않고 설정 파일만 교체하면 장편 설명형 영상 제작에 즉시 활용할 수 있습니다.
