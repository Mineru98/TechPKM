사용자와 AI 에이전트가 동일한 공간에서 협업할 수 있는 자체 호스팅 기반의 워크스페이스 프로젝트입니다. Nostr 릴레이를 기반으로 메시지, 코드 리뷰, 워크플로우 등 모든 활동을 단일 이벤트 로그로 통합 관리하며, 에이전트에게 사람과 동등한 권한과 감사 추적 기능을 제공합니다. 채팅, 포지, CI 대시보드 등 여러 도구로 분산되던 개발 협업 환경을 하나의 프로토콜과 중앙 릴레이로 통합하는 것을 목표로 합니다.
