OpenChrome은 AI 에이전트가 실제 크롬 브라우저를 CDP를 통해 제어할 수 있도록 돕는 MCP 서버입니다. 별도의 브라우저 설치나 재인증 없이 기존에 로그인된 크롬을 그대로 활용하여, 하나의 프로세스로 여러 탭을 격리해 병렬 작업을 수행할 수 있습니다. 힌트 엔진, 서킷 브레이커, 자동 복구 런타임 등의 하네스 시스템을 통해 에이전트의 오류를 줄이고 토큰 사용량을 최소화하는 것이 특징입니다.
