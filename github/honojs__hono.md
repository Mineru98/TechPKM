Hono는 일본어로 "불꽃🔥"을 의미하며, Web Standards 기반으로 구축된 작고 가볍고 매우 빠른 웹 프레임워크입니다. Cloudflare Workers, Deno, Bun, AWS Lambda, Node.js 등 어떤 JavaScript 런타임에서도 동일한 코드로 동작하는 멀티 런타임 지원이 핵심 특징입니다. 내장 미들웨어, 최소 12kB의 경량 번들, 우수한 TypeScript 지원으로 개발자 경험(DX)을 제공합니다.
