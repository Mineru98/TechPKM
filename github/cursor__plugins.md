Cursor 공식 플러그인 마켓플레이스 저장소로, 개발자 도구·프레임워크·SaaS 제품을 위한 공식 플러그인 모음을 제공한다. 각 플러그인은 저장소 루트의 독립 디렉터리에 `.cursor-plugin/plugin.json` 매니페스트와 skills, rules, MCP 서버 정의를 포함하며, 루트의 `marketplace.json`이 전체 플러그인 목록을 관리한다. 개발 워크플로우 자동화(코드 리뷰, CI, 오케스트레이션)부터 Gmail, Salesforce, GitHub 등 다양한 서드파티 SaaS 통합까지 폭넓은 플러그인을 제공한다.
