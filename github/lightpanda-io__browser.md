AI 에이전트 및 웹 자동화를 위해 처음부터 새로 작성된 경량 헤드리스 브라우저입니다. Chromium이나 WebKit을 기반으로 하지 않고 Zig 언어로 개발되어 메모리 사용량은 크롬 대비 1/9, 실행 속도는 11배 더 빠른 성능을 제공합니다. CDP를 통해 Puppeteer, Playwright 등과 호환되며, 스크래핑, 테스트, LLM 학습 데이터 수집 등 최적화된 서버 사이드 브라우징 환경을 제공합니다.
