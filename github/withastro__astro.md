현대 웹을 위한 정적 웹사이트 빌드 도구로, 강력한 개발자 경험과 가벼운 출력 결과를 제공합니다. React, Vue, Svelte 등 다양한 UI 프레임워크를 통합하여 사용할 수 있으며, 기본적으로 아일랜드 아키텍처를 채택하여 불필요한 자바스크립트를 제거합니다. 콘텐츠 중심의 빠르고 최적화된 웹사이트를 구축하는 데 적합합니다.
