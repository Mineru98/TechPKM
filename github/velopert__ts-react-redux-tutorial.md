타입스크립트 기반의 리액트 프로젝트에서 리덕스를 타입 안전하게 사용하는 방법을 단계별로 설명하는 튜토리얼 프로젝트입니다. 기초적인 카운터와 투두리스트 구현부터 typesafe-actions를 활용한 리팩토링, 그리고 redux-thunk와 redux-saga를 이용한 비동기 작업 처리 및 커스텀 유틸 함수로의 최적화 과정을 10개의 브랜치로 나누어 제공합니다.
