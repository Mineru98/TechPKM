Adobe After Effects에서 Bodymovin 플러그인을 통해 JSON으로 내보낸 애니메이션을 웹에서 네이티브하게 렌더링해 주는 라이브러리입니다. 개발자가 직접 애니메이션을 코드로 재구현할 필요 없이, 디자이너가 만든 고품질 애니메이션을 쉽게 웹 프로젝트에 적용할 수 있도록 지원합니다. SVG, Canvas, HTML 등 다양한 렌더러를 제공하며 재생 제어 및 이벤트 처리 기능을 갖추고 있습니다.
