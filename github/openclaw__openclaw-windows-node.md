AI 기반 개인 비서인 OpenClaw를 위한 Windows 전용 컴패니언 애플리케이션입니다. WinUI 3 기반의 시스템 트레이 앱을 통해 게이트웨이 연결 상태 모니터링, 채팅, 딥 링크 자동화 등의 기능을 제공하며, 노드 모드 활성화 시 에이전트가 Windows PC의 시스템 명령, 스크린샷, 카메라 등을 제어할 수 있습니다.
