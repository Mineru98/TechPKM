GPT-4 기반 자율형 에이전트인 Auto-GPT의 실험적 기능을 웹 UI(Pynecone)와 지식 그래프(d3.js)로 시각화하는 프로젝트입니다. 이 프로젝트는 AI가 스스로 계획을 수립하고 정보를 수집하는 과정을 시각적으로 모니터링할 수 있는 환경을 제공합니다. Python으로 작성되었으며, OpenAI API를 활용하여 복잡한 작업을 자동화하고 그 결과를 힘 기반 그래프로 탐색할 수 있도록 지원합니다.
