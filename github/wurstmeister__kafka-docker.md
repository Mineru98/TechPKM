Apache Kafka를 Docker 컨테이너로 쉽게 실행하고 관리할 수 있도록 제공되는 Dockerfile 및 docker-compose 설정 프로젝트입니다. 다중 브로커 스케일링, 리스너 설정, 토픽 자동 생성, JMX 모니터링 및 Docker Swarm 모드 배포를 환경 변수를 통해 유연하게 제어할 수 있는 것이 핵심 특징입니다.
