네이버 AI(Naver AI)가 공개한 실제 대도시(서울)의 데이터를 기반으로 세계 시뮬레이션 모델을 학습시킨 프로젝트입니다. 연구 논문 "Grounding World Simulation Models in a Real-World Metropolis"의 공식 코드를 포함하며, 모델 체크포인트와 가상 훈련 데이터 등을 공개할 계획을 가지고 있습니다. 실제 도시 환경을 시뮬레이션하여 자율주행 등 자율 에이전트 학습을 위한 합성 데이터를 생성하는 것을 목표로 합니다.
