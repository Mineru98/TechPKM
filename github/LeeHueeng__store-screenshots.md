Claude Code 및 OpenAI Codex 에이전트를 위한 스킬로, 원본 앱 스크린샷을 앱스토어와 구글 플레이 스토어에 바로 사용할 수 있는 마케팅 이미지로 자동 변환합니다. CSS로 그린 디바이스 프레임, 앱의 실제 디자인 색상을 반영한 배경, 화면 분석 기반의 마케팅 카피를 결합하며, 에이전트가 직접 앱을 실행해 스크린샷을 캡처하는 기능도 지원합니다. 모든 작업이 로컬에서 헤드리스 크롬을 통해 이루어지므로 외부 업로드나 워터마크 없이 완전한 프라이버시를 보장합니다.
