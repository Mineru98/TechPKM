한국 스타트업·1인 법인·프리랜서·개인사업자를 위한 장부 자동 생성 Claude Code 스킬 패키지. 카드명세서 PDF, 은행 CSV, 영수증 이미지 등을 입력하면 표준 거래내역, 계정과목 매핑, 재무제표(BS·PL), 세무사 전달용 CSV를 자동 생성하며, CODEF 연동을 통한 홈택스·은행·카드 데이터 자동 수집과 마스킹 기반 보안 모델을 갖추고 있다. 룰 기반 분류와 LLM fallback을 결합해 거래 분류를 수행하고, 경영용 현금흐름 대시보드와 종합소득세 준비 기능도 제공한다.
