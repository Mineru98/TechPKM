Claude Code 및 Gemini CLI 환경에서 AI 에이전트가 직접 활용할 수 있도록 작성된 디자인 스킬 및 명령어 모음집입니다. 사용자 리서치부터 UX 전략, UI 설계, 인터랙션 디자인, 디자인 시스템 구축에 이르기까지 총 239개의 스킬과 88개의 명령어를 5개 컬렉션으로 제공하며, 사람이 읽기 위한 지식이 아닌 에이전트가 문자 그대로 해석하고 실행할 수 있도록 디자인의 판단 기준을 명확하게 문서화한 것이 특징입니다.
