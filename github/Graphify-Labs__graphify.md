Graphify는 AI 코딩 어시스턴트에서 `/graphify` 명령 하나로 코드, 문서, PDF, 이미지, 영상 등 프로젝트 전체를 지식 그래프로 변환해 주는 CLI 도구입니다. 코드는 tree-sitter AST를 통해 로컬에서 LLM 없이 결정적으로 파싱되며, 벡터 인덱스가 아닌 실제 그래프를 순회하여 질의(query), 경로 탐색(path), 개념 설명(explain)을 수행할 수 있습니다. 약 40개 언어를 지원하고 Claude Code, Cursor, Codex 등 20개 이상의 어시스턴트와 연동되며, 항상 최신 그래프를 유지하는 Graphify Cloud를 통해 에이전트 토큰 비용 절감, 모노레포 지원, 형식 검증 등의 기능도 제공합니다.
