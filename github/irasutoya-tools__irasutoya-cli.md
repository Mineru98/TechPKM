이라스토야(Irasutoya)의 무료 일러스트를 터미널에서 직접 검색하고 미리보기할 수 있는 Ruby 기반 CLI 도구입니다. 키워드 검색 또는 랜덤 추출 기능을 제공하며, iTerm2나 libsixel이 설치된 환경에서는 이미지를 터미널 내에서 바로 확인할 수 있습니다.
