순환 신경망 언어 모델(RNNLM)을 활용하여 단어 시퀀스의 의미적 타당성을 고려하는 새로운 형태소 분석기입니다. 버전 2는 기존 Juman++ 대비 정확도가 향상되었으며, 분석 속도가 250배 이상 크게 개선되었습니다. 주로 일본어 텍스트 분석에 사용되며, 사전 학습된 모델을 통해 즉시 형태소 분석을 수행할 수 있습니다.
