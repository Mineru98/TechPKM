Google Antigravity CLI(`agy`)의 `/usage` 쿼터 조회 기능을 Antigravity IDE, Antigravity 2.0, Claude Code 등 모든 에이전트 채팅 환경에서 슬래시 명령어나 자연어로 사용할 수 있게 해주는 글로벌 스킬입니다. 모델별 잔여 쿼터와 리셋 시각을 마크다운 테이블로 시각화하여 보고하며, 터미널 단독 실행과 JSON 출력 등 CLI 플래그도 지원합니다.
